## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

## 🎯 它解决什么问题

| 你的处境 | 这个工具包给什么 |
| --- | --- |
| 有产品想法，但不会写代码 | AI 替你写全部代码，你只做业务判断 |
| 网上教程太技术、太碎片 | 内置三份技术手册，AI 按阶段自动读取 |
| 不知道"做到哪算好" | 每个阶段有明确闸门和证据包，你能自己核对 |
| 卡在云平台、密钥、备案 | 上线阶段有"照着点"清单，注册/认证/开权限都有引导 |

## 🚀 快速开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

> 📖 完整操作手册见 [开始看这里.md](./开始看这里.md)。

### 启动后端（本地）

```bash
cd backend
../.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 启动前端（本地，需 Node 22）

```bash
cd frontend
npm install   # 首次
npm run dev   # http://localhost:3000
```

访问开发版时使用 `http://localhost:3000`。若当前受限运行环境无法启动 Turbopack 的子进程，可用 `npm run dev -- --webpack`。不要同时启动两份同目录的开发服务。

### 检查前端与生产预览

在 `frontend/` 目录执行：

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run start -- -p 3100
```

生产预览地址为 `http://localhost:3100`，需要同时运行 8000 端口的后端。构建时可用 `BACKEND_URL=http://127.0.0.1:8001 npm run build` 指向独立后端；未设置时默认使用 8000 端口。前端组件测试用 Vitest + React Testing Library（`npm run test`），覆盖导航八入口、语块卡空状态；页面级链路仍靠浏览器走查与后端集成测试。2026-09-23：类型检查、Lint、组件测试、默认 Turbopack 生产构建均通过，后端 Mock 回归 111/111。

### 前端代码位置

- `frontend/app/page.tsx`、`page.module.css`：首页准备与设置。
- `frontend/app/practice/[sessionId]/`：对话、录音、跟读与回顾及页面样式。
- `frontend/app/history/page.tsx`、`memory/page.tsx`：历史与学习记忆。
- `frontend/components/`：导航、图标、音频组件；`frontend/app/globals.css`：共享设计变量和界面样式。
- `frontend/lib/api.ts`、`types.ts`：统一 API 请求与类型。
- `backend/app/services/prompts/scenarios.py`：七个场景的版本化配置（scene_id / series / goal / openings / 审核状态）。

记忆设置新增只读 `GET /api/v1/users/me/memory`，沿用邀请凭证鉴权，返回 `{ "enabled": boolean }`；错误沿用 `{ "error": { "code", "message" } }`。刷新页面直接读取数据库中保存的选择，不再重置为前端默认值。

四类求助（REQ-05）改由 `app/services/help_svc.py` 确定性编排：`repeat` 复用当前问题音频（零模型/零计费）、`explain` 返回场景中文解释、`organize` 后端按同题已展示记录逐级关键词→半句→完整、`translate` 用专用翻译 Prompt 且需 `source_text`（幂等）。帮助记录绑定 `question_id` 与 `is_answer_help`；organize/translate 为答案帮助（后续回答判 hinted），repeat/explain 为理解辅助（不取消独立）。

TTS 已加有限重试与文字降级：合成失败不影响文字回合（`audio_status=failed`），回合 SSE 顺序为 `chunk`（文字）→ `done`（含音频）；另提供音频重试接口 `POST /api/v1/sessions/{id}/turns/{turn_id}/audio`（鉴权、幂等）。评估器已按每场景 `subgoal_standard` 收紧，极简/模糊回答不再标独立。

P1-1 脱稿阶梯（REQ-28）：五段阶梯 `full_text→fill_blanks→structure→free_speak→transfer`，帮助证据决定完成结论（看全文/补关键词=有参考、看结构=提示下、脱稿说=独立、换题=迁移），结果写回待复练。接口：`POST /api/v1/sessions/{id}/drill-attempt`（提交尝试）、`POST /api/v1/sessions/{id}/drill/action`（skip/downgrade/end）。

P1-2 今日复练组合（REQ-29）：从待复练队列选已到期、来源有效的 3~5 条组成一次连续练习，按间隔档位 1/3/7/14 推进，结果写回同一套队列。接口：`GET /api/v1/review-queue/due-today`、`POST /api/v1/review-queue/daily-review/start`、`GET/POST /api/v1/review-queue/daily-review/{session_id}[/attempt|/action]`。

P1-3 示范与本人录音对比（REQ-30）：跟读提交后保存本人录音供回放（`recording_url`），评价绑定录音版本/参考句版本/阶梯阶段；前端支持慢速示范（0.75x）与示范/本人录音互斥播放；录音随会话清理。

P1-4 语块卡（REQ-31）：从有效建议确定性生成（来源原句/建议表达/主要语块/中文解释/适用情境/可替换部分/新例句，不扩写用户事实），来源失效传播。接口：`POST/GET /api/v1/phrase-cards`。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 删密钥 | 删云密钥 | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表）。是否表有"否"就不能说完成。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 正式上线的默认方案需要云平台企业认证。没有的话，AI 先用临时方案上线并明确三条限制，认证办好后再切换。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。
