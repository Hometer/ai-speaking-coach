# AI 口语项目 · 使用引导

本目录是「AI 口语练习」产品的需求与推导工作区。引擎是上一级的 `agent-blueprint` 目录，本目录只放产品资料，不写引擎代码。

## 一、文件放哪

```
agent-blueprint-main/          ← 引擎（工具，别改它）
├── blueprint/                 ← 引擎核心
├── s01 ~ s17/                 ← 组件参考
├── out/                       ← 推导结果写这里
└── AI口语/                    ← 本目录（产品资料）
    ├── AI口语练习PRD-v0.1.md       ← PRD（当前 v0.4 质检修订稿）
    ├── 国内AI口语竞品扫描-2026-09-18.md
    └── 使用引导.md                  ← 本文档
```

> 说明：理想情况 PRD 应放在引擎目录外，避免反向扫描时把 s01~s17 一起扫进去。当前 PRD 已放在引擎目录内，正向推导（plan）不受影响；若以后做反向审计，目标项目请放到引擎外。

## 二、项目现状（已确认）

| 项 | 结论 |
| --- | --- |
| MVP 范围 | 18+ 受邀内部用户；回合制；英文面试自我介绍一个场景（含嵌入式短句跟读）；记忆默认关闭 |
| 时延目标 | 普通回合 P50 ≤ 2.5s、P95 ≤ 5s |
| 成本目标 | 标准 5 分钟练习变动成本 ≤ ¥1 |
| 非目标 | 首期不做多 Agent 团队、定时训练、插件市场、复杂任务调度 |
| PRD 状态 | v0.4 质检修订稿，MVP 需求基线 |

## 三、组件选型结论（已用规则引擎确定，可直接引用）

| 决策 | 组件 | 依据 |
| --- | --- | --- |
| ✅ 必选 | s01 Agent Loop | 恒选，最小闭环 |
| ✅ 必选 | s02 工具系统 | 恒选，ASR/TTS/评测等外部调用 |
| ✅ 必选 | s03 权限系统 | 语音/文本隐私、删除记录、跨用户身份隔离、默认拒绝 |
| ✅ 必选 | s04 钩子系统 | 记录行动类型、触发依据、证据回合、用量 |
| ✅ 必选 | s17 目标闭环 | 独立评估器判断完成，区分独立/提示下完成 |
| ✅ 必选 | s15 集成 Harness | 上述 3 个可选组件归一到单一循环 |
| ⏸ 二期 | s07 技能加载 | 多场景时再上 |
| ⏸ 二期 | s08 上下文压缩 | 长会话时再上 |
| ⏸ 二期 | s09 记忆系统 | PRD 明确记忆默认关闭，二期 |
| ❌ 放弃 | s05/s06/s10/s11/s12/s13/s14/s16 | 单场景、无定时、无团队、无插件、非固定编排 |

核心判断：本产品的 Agent 灵魂是 **s17 目标闭环**（PRD 8.1 完成条件 + 10.1 独立完成判断）。

## 四、下一步（按顺序）

1. **产出完整架构方案**：七层架构图 + 工具契约（ASR/TTS/评测/评估/记忆 的输入输出与权限）+ 系统提示词草案。方式二选一：
   - 当前 AI 按手册手写（标注「非模型管线」）；
   - 配置 `.env` 的 `ANTHROPIC_API_KEY` + `MODEL_ID`（支持 DeepSeek/智谱/Kimi 等兼容网关）后跑真实管线。
2. **方案确认后**进入 Step 5 代码生成：骨架 → 硬化 → 产品化。
3. **内部验证**按 PRD 第 11 节指标执行。
