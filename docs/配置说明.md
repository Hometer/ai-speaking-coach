# 配置说明

复制根目录 `.env.example`。本地演示用 `PROVIDER_MODE=mock`，启动时显式启用 `SEED_DEMO_INVITES=1`，首页使用代码内的演示凭证 `test-a`；它仅供开发，生产禁止启用。真实模式用 `PROVIDER_MODE=real` 并自行配置百炼 Key；讯飞评测需要另外三项配置，实际词级效果待验。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| PROVIDER_MODE / DASHSCOPE_API_KEY | 根目录 `.env` | mock 离线；real 调用真实服务 |
| XF_APPID / XF_API_KEY / XF_API_SECRET | 根目录 `.env` | 发音评测配置，词级结果仍需验收 |
| UPLOAD_RETENTION_MINUTES / SESSION_RETENTION_DAYS | 根目录 `.env` | 录音与文本留存期限 |
| BACKEND_URL | 前端进程环境 | 默认 `http://127.0.0.1:8000`；改后端时同步 |
| PRICE_BOOK_PATH | 后端进程环境 | 可选，本机费率 JSON；未配置时供应商估算为未知 |

## 本机数据与验证

`frontend/` 为 Next.js 学习界面，`backend/` 为 FastAPI 服务；SQLite 和音频保存在被忽略的 `data/`。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

## 审计修复后的恢复与学习证据

重复提交必须沿用原请求键；同键同内容重放首次结果，内容改变返回 409。刷新会显示正在处理状态并查询已保存记录。服务重启发现未决请求时显示“待核对”，不会自动重复可能计费的供应商调用。需要继续练习时先确认已保存内容，再主动发起新操作。

待复练与今日复练先回忆、再回答新条件；回忆成功本身不增加独立成功次数。文字、看提示、跟读分别记录，不能代替无帮助语音迁移。来源修订、争议或删除会使相应派生材料和缓存失效。

当前后端 195 项、前端 6 项离线测试通过；类型、Lint、生产构建通过。查看[本轮修复与证据](evidence/阶段3-v0.10审计修复-20261015/验收记录.md)。旧“离线缺陷复现”脚本用于基线提交 cbca61a，修复后使用 pytest 回归，不再用“缺陷应复现”的断言验收。

## 供应商估算与账单核对

费率文件建议放在已忽略的 `data/price-book.local.json`，不写任何密钥。下面仅定义格式，尖括号字段要填供应商已经核对的人民币单价，不能直接作为有效费率使用：

```json
{
  "version": "2026-10-15-reviewed",
  "currency": "CNY",
  "rates": {
    "llm:qwen-plus": {"source": "<合同或官方价格版本>", "input_per_million": "<单价>", "output_per_million": "<单价>"},
    "tts:cosyvoice-v2": {"source": "<价格版本>", "per_character": "<单价>"},
    "asr:paraformer-realtime-v2": {"source": "<价格版本>", "per_second": "<单价>", "round_seconds": 1, "minimum_seconds": 0},
    "ise:xfyun_open_ise": {"source": "<价格版本>", "per_call": "<单价>"}
  }
}
```

组件与模型名称要匹配实际用量记录，计费单位、取整和最低计费按真实规则填写。缺费率、缺可信计量或失败调用未报告用量时保持未知。该估算不替代账单。

内部账单 CSV 为 `usage_event_id,amount_cny,reference` 三列，reference 为唯一供应商账单行标识，不放用户正文。核对脚本默认仅显示行数，不写库；确认每条调用及金额后才用 `--apply`。每条写入原子、重复行不重复计费；后续行失败时前面已核对行保留，可纠正后重跑。

```bash
cd backend
../.venv/bin/python scripts/reconcile_bills.py /本机路径/bill.csv
../.venv/bin/python scripts/reconcile_bills.py /本机路径/bill.csv --apply
```

名义预算预留、供应商估算和已核对实付分别展示。预算会参考已核对实付，但调用前预留仍为配置名义值，真实硬上限须经费率及失败重试账单校准验收。
