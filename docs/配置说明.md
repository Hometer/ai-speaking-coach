# 配置说明

复制根目录 `.env.example`。本地演示用 `PROVIDER_MODE=mock`，启动时显式启用 `SEED_DEMO_INVITES=1`，首页使用代码内的演示凭证 `test-a`；它仅供开发，生产禁止启用。真实模式用 `PROVIDER_MODE=real` 并自行配置百炼 Key；讯飞评测需要另外三项配置，实际词级效果待验。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| PROVIDER_MODE / DASHSCOPE_API_KEY | 根目录 `.env` | mock 离线；real 调用真实服务 |
| XF_APPID / XF_API_KEY / XF_API_SECRET | 根目录 `.env` | 发音评测配置，词级结果仍需验收 |
| UPLOAD_RETENTION_MINUTES / SESSION_RETENTION_DAYS | 根目录 `.env` | 录音与文本留存期限 |
| BACKEND_URL | 前端进程环境 | 默认 `http://127.0.0.1:8000`；改后端时同步 |

## 本机数据与验证

`frontend/` 为 Next.js 学习界面，`backend/` 为 FastAPI 服务；SQLite 和音频保存在被忽略的 `data/`。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

## 工程检查

以下为离线工程检查入口；历史真实模型脚本可能产生费用，请先阅读对应验收记录。

```bash
(cd backend && PROVIDER_MODE=mock ../.venv/bin/python -m pytest -q)
npm --prefix frontend test
npm --prefix frontend run typecheck
npm --prefix frontend run lint
npm --prefix frontend run build
```

本次 GitHub 整理不追加真实模型调用，也不改变产品阶段验收结论。历史开发过程见 [开发记录](历史/开发记录.md)。
