# 前端技术适配声明

> 项目：AI 口语练习（后端 MVP 已完成）。依据：PRD v0.4、前端手册、后端接口（已实现）、通用手册。

## 1. 项目判断

- 产品类型：AI 口语练习（回合制语音/文字对话 + 跟读评测 + 练习回顾 + 历史/记忆）。
- 主要用户：18 岁及以上受邀内测用户，中文界面引导。
- 主要终端：桌面 Web（优先）；移动 Web 保持基本可读、可操作。
- 新项目或已有项目：新前端（后端 `backend/` 已就绪，现临时验收页 `static/index.html` 将被替换）。
- 本阶段业务目标：把临时验收页升级为正式前端，先跑通"开始练习 → 多轮语音/文字对话"第一条真实闭环。

## 2. 输入资料

- PRD：已读取。
- 后端手册：已读取。
- 接口文档：已就绪（`backend/app/api/routes.py` + 阶段 2.1~2.3 文档）。
- 设计稿：无（待产品经理给视觉方向，见第 7 节）。
- 现有代码：有（后端 API + 临时 HTML 验收页）。

## 3. 技术选择

- 框架与版本：Next.js（App Router）+ TypeScript（strict）。
- 样式与组件策略：Tailwind CSS + 语义化设计变量（CSS 变量）；优先原生 HTML + 轻量自建组件，暂不引入完整组件库。
- 数据请求与状态策略：集中式 API 层（`fetch` + SSE 解析）；状态用 React 内置 + 少量 Context，暂不引入状态库。
- 流式通信策略：普通回合用 SSE（`chunk → done/error`）；跟读评测为同步接口。
- 表单方案：受控组件 + 原生校验（文字 1~2000 字符）。
- 测试方案：`tsc --noEmit` + ESLint + 组件/E2E 最小集（每阶段至少 `lint / typecheck / test / build`）。
- 部署环境：阶段 4 再部署；前端为独立 Next.js 产物，`rewrites` 同源代理 `/api/*` 到后端。

## 4. Agent 状态

- 后端状态 → 前端映射：`WAITING_INPUT`=等待回答、`PROCESSING`=处理中、`PRACTICE`=跟读中、`RECHECK`=复测中、`PAUSED`=已暂停、`ENDED`=已结束。
- 等待用户确认方式：跟读由用户点击"录音跟读"进入（对应 PRD 的接受/跳过）；提示直接展示。
- 取消、重试、断线恢复：录音可取消（不提交）；请求失败可重试；会话 ID 存 `localStorage`，刷新后回到当前会话继续。
- 任务 ID 和恢复入口：会话 ID 作为恢复锚点，历史页可回到详情。

## 5. 页面与产物

- 核心页面：首页（单场景入口 + 复练入口 + 未开放模式"暂未开放"）、对话页（录音/文字/转写/跟读/进度/结束）、回顾页、历史页（列表/详情/删除）、设置/记忆面板。
- 核心业务闭环：开始练习 → 回答 → 看到转写与 AI 回复 → 播放语音 →（跟读/复测）→ 结束 → 看回顾。
- 产物类型和预览方式：AI 语音与示范音为 `<audio>` 播放；回顾为结构化文本。
- 响应式目标：桌面优先，移动端 375px 宽度可用。

## 6. 偏离本手册的地方

- 暂不引入完整组件库：本产品组件简单（按钮/卡片/录音/播放器），原生 + Tailwind 足够，避免为"技术栈完整"引入重型依赖。
- 暂不做登录：内测阶段用 `X-User-Id`（demo 身份），正式登录/邀请码在阶段 4 上线时接入。
- 暂不引入状态库：状态简单，React 内置足够；出现跨页共享复杂状态再评估。
