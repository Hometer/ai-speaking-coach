## 1. 详细设计

### 1.1 resolve_audio_for_user 增查 pending_risk

`resolve_audio_for_user` 找不到 Turn 时，遍历 `Session.pending_risk != ""` 的会话，解析 JSON 比对 `recording_url`；命中且用户匹配则返回，否则继续 404。

### 1.2 confirm_turn 按 action 分模态

`action == "text_fallback"` → `submit_turn(..., "text", user_text=confirmed_text)`；其余 → `submit_turn(..., "voice", pre_transcribed=confirmed_text)`。

### 1.3 judge_transfer 严格化

`judge_transfer(answer, original, input_type, help_shown, reference_expressions)`：
- 语音 + 非照抄 + ≥3 词；
- 与 reference_expressions 的内容词重叠数 ≥2 才 `transfer`，否则 `pending`。
`drill_svc` 只传 `reference_expressions`。

### 1.4 幂等

- `submit_retest`：幂等检查移到到期检查之前；同键同答返回当前，异答 409。
- `submit_drill_attempt` / `submit_attempt`：幂等检查移到状态检查之前；同键异文本 409。
- migrate_db：drill_attempts、daily_review_attempts 建 `(session_id, attempt_key)` 唯一索引（先清空键去重）。

### 1.5 计划完成按天

`training_plan._to_dict`：统计计划创建后各场景「结束且有回顾」的会话数，按 day 升序给对应场景的待练日逐一点亮（每场景消费一个完成数）。

### 1.6 进步口径

`progress.get_progress`：`independent_count`、`by_scene`、`trend` 只取 `input_type == "voice"` 的评价。

### 1.7 SSE 收尾

`routes.voice_turn_stream`：risk_hold 后 yield `done` 事件（与 risk_hold 同 data）。

### 1.8 历史 completed 口径

`session_svc.list_sessions`：`status=completed` 过滤普通场景（非 single/daily）须 `review != ""`。

### 1.9 计划页展示

`plan/page.tsx`：completed 显示「已完成」徽标。
