## 1. 目标和范围

用户在风险转写、重试、复练、计划、历史与质检流程中看到的状态，应由可恢复、可追溯的服务端事实支持。本批关闭复核报告列出的本地代码缺口。保留现有功能与用户数据，采用增量迁移。真实 ASR、讯飞词级、真机、人工教学评分、供应商账单和四周内测另列待验，不以 Mock 冒充。

## 2. 实施顺序和接口契约

| 批次 | 工作 | 请求/响应与错误 | 最低回归 |
| --- | --- | --- | --- |
| A 安全与证据 | 风险卡加“改用文字”；待确认录音纳入引用、删除与过期清理；生产禁用固定演示邀请 | 确认接口保留 `action=text_fallback`，返回 `text_completed`；缺失/越权仍按 `{error:{code,message}}`；生产配置错误启动失败 | 文字不计语音；本用户可听回、他人拒绝；确认、超时、删除均无孤儿录音 |
| B 用户意图幂等 | 创建会话、普通文字/语音回合、风险确认、复测、今日复练与脱稿统一请求键和同键同内容约束；先重放后状态检查 | 同键同请求返回第一次结果；同键异内容 409 `IDEMPOTENCY_CONFLICT`；SSE 以 `done`/`error` 结束 | 结束/暂停后重放、双击、冲突、语音上传键、跨用户隔离 |
| C 学习结论 | 换题判定缺参考或新条件证据时保守 `pending`；计划关联具体日期/场景/会话；到期快照和前后七次口径 | 保持现有响应字段，新增有来源的事实字段，不将未知当成功 | 无关/半相关换题不升级；跨日与重建计划；删除来源重算 |
| D 页面闭环 | 历史系列/场景/复练状态；计划可用时间；质检多维筛选、费用/时延/争议/版本；设备短录听回与用户确认 | 列表筛选参数均经后端校验；空/错/加载分离 | 页面交互与 API 集成，390/768/1280/1440 宽度 |
| E 质检录音与费用 | 质检录音独立授权、撤回、访问审计、7 天清理；分组件采集用量与估算费用、失败重试记录，不把估算称实账 | 默认拒绝录音访问；仅授权审核员可用；撤回即拒绝；账本区分 `estimated` 与 `billed` | 未授权 403、授权/撤回/过期/审计；供应商故障注入、估算与实账不混用 |

## 3. 数据与迁移

- 幂等键绑定用户、动作、请求摘要和结果引用；已有空键历史记录保持兼容，新增键使用唯一约束，不清空旧业务记录。
- 待确认录音写明确的持久化引用与创建时间；清理任务按最迟 24 小时处理，确认/重录/删除即时解绑并删除；不得仅靠会话文本 30 天清理。
- 计划日完成记录应绑定计划 ID、天序、会话 ID 和完成日期；历史计划不虚构完成证据，旧数据展示为待核对或用明确可追溯规则迁移。
- 到期复练保存到期时刻/完成时刻，统计按观察窗口内真实到期快照；删除或失效后不贡献分母/分子。
- 质检授权与访问日志独立于普通录音；未授权不复制音频。授权最多 7 天，撤回和到期删除副本或撤销引用。
- 费用区分供应商返回的原始用量、由单价计算的估算和对账后的实账；预算在调用前确定性预留，不能把估算列命名为供应商实账。真实价格与重试费以供应商账单校准。

## 5. 验收与阶段闸门

先做针对复核报告反例的后端/组件测试，再执行全部后端 Mock、前端类型/Lint/组件/生产构建。使用隔离 SQLite 验证重启恢复、迁移和录音删除。启动项目做桌面与移动宽度走查，关键页面截图与“照着点”步骤放 `docs/evidence/阶段3-v0.10本地收口/`。更新 README、项目状态、阶段闸门是否表。任一本地项未完成、真实模型待验或真机未验时，阶段保持未通过。

## 6. 风险与回退

数据迁移只新增表、列和索引，先检查重复键与旧记录。删除音频只删除本应用音频目录中经过安全文件名校验的明确引用文件。费用护栏采用保守预留，供应商金额未知时不将估算当硬保证。每批保持旧 API 的兼容字段；新字段允许旧客户端忽略。发现迁移不兼容时回退代码，保留数据库新增字段与旧数据。
