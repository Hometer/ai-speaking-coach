## 1. 第一部分设计：前端语音收尾

### 1.1 复用现有录音组件

`frontend/app/practice/[sessionId]/page.tsx` 已有 `recRef` 录音能力（`toggleRecord("answer"/"practice")`）。为脱稿阶梯与今日复练复用同一录音链路：

- 脱稿阶梯页（`practice/[sessionId]` 的 drill 卡）：`full_text/fill_blanks/structure` 允许文字；`free_speak/transfer` 用录音提交（`input_type="voice"`）。文字在 free_speak/transfer 阶段提交时，前端提示"这一级需要语音"并默认走录音。
- 今日复练页（`daily-review`）：每条提供录音按钮，提交带 `input_type="voice"`。
- 待复练队列页（`queue`）：复测加录音按钮（语音可计独立，文字只计文字完成）。

### 1.2 API 已就绪

后端 `submit_turn`/`drill_attempt`/`daily_review_attempt`/`submit_retest` 均已支持 `input_type`；`voice_turn_stream` 已存在。本批只补前端录音与提交参数，不改后端判定逻辑。

## 2. 第二部分设计：P0-B

### AC10-13 设备预检 + 帮助层级（`frontend/app/page.tsx`、`help_svc.py`）

- `checkDevice` 拆四项：麦克风权限、录音输入、音频播放、网络连通，逐项给状态与"照着做"修复提示（复用 PRD 设备预检口径）。
- 预检任一失败仍可文字练习，页面说明"文字不参与发音/语音独立"。
- 帮助面板：`repeat` 提供慢速（0.75×）重播入口；`organize` 层级由后端记录并在刷新后从会话恢复显示（`get_session_detail` 返回 `current_help_level`）。

### AC10-14 历史筛选（`history/page.tsx`、`session_svc.list_sessions`）

- `list_sessions` 增加过滤参数：`series`、`scene_id`、`status`（含完成/未完成）、`practice_type`（普通/单句/今日复练）。
- 前端历史页增加筛选条（系列/场景/完成状态/类型）。
- "再练一次"默认保留原会话的 level 与 scene_id，创建新会话（不再固定 `basic`）。

### AC10-15 进步指标口径（`progress.py`）

- 独立率分母 = 有评估结果的子目标数（不是评估回合数）。
- 到期复练完成率分母 = 已到期项目数（不是"已有复测结果"）。
- 普通场景完成数 = 已结束且有回顾的普通场景会话。
- 删除/失效来源后重算相关指标；保留 `calc_version` 递增。

### AC10-16 事件埋点（`session_svc.py`、`progress.py` 等）

- `EventLog` 增加 `request_key` 用于去重；失败/退出仍记录（保留在分母）。
- `duration_ms`、`usage` 由调用实值填充（LLM tokens/TTS 字符）——mock 填 0 或占位，real 由 `generation_call` 返回 usage。
- 不把正文/中文原意/录音写入 EventLog（只记状态/用量/错误码）。

### AC10-17 质检录音 + 语块卡（`quality_label.py`、`phrase_card_svc.py`、`cleanup.py`）

- 特别授权质检录音：新增授权标记 + 7 天删除（复用 cleanup 的 `upload_max_age` 或独立 7 天上限）；访问留痕。
- 语块卡：`generate_card` 增加并发唯一约束（`(user_id, source_turn_id)` 唯一），同来源只产生一张；删除来源清除副本（已有传播，补并发兜底）。
