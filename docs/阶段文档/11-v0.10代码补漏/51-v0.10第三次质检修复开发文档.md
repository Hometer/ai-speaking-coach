# v0.10 第三次质检修复开发文档

创建：2026-10-16。阶段：3 正式前端；基线 `890651b`。本文在业务代码修改前创建。用户授权先文档、再开发、最后本地 Git 提交。依据第三次质检的 17 项问题和 PRD v0.10；沿用现有技术栈，不新增付费资源、不调用真实供应商、不部署。

## 修复契约

| 问题 | 实现与通过条件 |
| --- | --- |
| Q3-01 | 删除、争议、修订统一撤销参考句副本、评测与操作快照；保留用户自己新说的回答。 |
| Q3-02 | 临时上传按会话归属，ASR 成功/异常 finally 删除；主动删除能清理在途文件及转码副本。 |
| Q3-03 | 每个新 TTS 尝试受三层预算约束，调用前标记、失败保守结算；缓存播放零调用。 |
| Q3-04 | 确认风险转写前核对音频归属、版本及保留期；过期返回明确重录提示，不能形成语音证据。 |
| Q3-05 | 所有录音入口以授权代次和生命周期接纳媒体；暂停、结束、卸载或取消后的流立即停止。 |
| Q3-06 | 阶梯、队列、今日复练共用风险门控；确认绑定原对象、阶段、状态版本及录音，未确认不推进。 |
| Q3-07 | 单句阶梯保存带参考/阶段版本的本人录音，提供鉴权播放、对比、重录；脱稿阶段不提前揭示答案，独立阶段不开放参考播放；无真实词级评测不编造分数。 |
| Q3-08 | 翻译与其他供应商分支调用前持久标记；迟到结果拒绝时保守记账，进入 provider 前失败可释放；已进入 provider 按尝试保守结算。 |
| Q3-09 | 语义待定/服务故障不移动 due，不解析原到期事件，不增加成功次数；允许新意图重试。 |
| Q3-10 | 恢复计划先核对真实完成日，再仅移动未解决日；来源失效仍可撤销完成结论。 |
| Q3-11 | 补词、结构、语块卡共用当前句的可靠材料，空缺来自原句 1～3 个语块；材料缺失明确不可用。 |
| Q3-12 | 重播统一使用带鉴权的播放器与页面播放生命周期，慢速播放不合成新音频。 |
| Q3-13 | 修订后统一接收完整详情，清除旧诊断、旧派生操作和旧评测状态。 |
| Q3-14 | 增加“删除全部计划”确认入口，删除本人活动及历史计划，解除练习关联，保留练习与队列。 |
| Q3-15 | 所有阶梯终态统一保存结束时间、原因并停止活动计时，重复请求不改原结束时间。 |
| Q3-16 | 校验整句/词分数有限且范围合法，词位置与当前参考一致；异常词降为整句结论，整句异常则不可评估。 |
| Q3-17 | 教学分支共用场景、角色、水平、难度、当前题与历史上下文；新题更新题目及帮助归属。 |

## 数据与接口

- 采用增量兼容迁移，为风险记录增加语音用途/对象/版本，为阶梯尝试增加本人录音、参考版本和示范引用。旧记录继续可读，不猜测缺失录音。迁移前 SQLite 原生备份，先在副本验证记录数和完整性。
- 语音提交原请求字段保持兼容；成功响应可返回 `risk_hold`、风险 ID、原转写及鉴权录音地址。新增 POST `/api/v1/voice-risks/{risk_id}/confirm`：请求 `{text, request_key}`；响应为原阶梯/队列/今日结果；同一确认键重放不重调 ASR。归属错误 404，过期 `AUDIO_EXPIRED`，对象/版本改变 `STALE_OPERATION`，格式非法 422。普通会话原确认接口保留。
- DELETE `/api/v1/training-plan` 无正文，返回 `{deleted: 数量}`；仅删除当前身份所有计划，解绑对应 Session.plan_id/plan_day，练习和复练证据保留。页面明确确认范围；鉴权沿用现有邀请隔离。
- 统一错误继续 `{error:{code,message}}`，SSE 继续 done/error 收尾；录音地址仅在后端归属校验后返回。新字段和快照纳入会话/来源删除、争议、到期清理。
- 演示音频只对应当前版本；自由表达不增加伪造的发音评分。真实 ISE、教学质量、账单仍待验。

## 实施记录

Q3-01～17 已实现并通过本地正确行为回归，[逐项结果、截图与闸门](../../evidence/阶段3-v0.10第三次质检修复-20261016/验收记录.md)。新增后端 66 项、前端 8 项；总计 317/317、25/25，类型、Lint 零警告、生产构建通过。

- 统一清理派生参考和快照，原始上传使用会话哈希前缀并 finally 回收源文件、旧转码文件及新 `.asr.wav`。附带解决 WAV 输入转码覆盖原文件的问题，真实本机 FFmpeg 离线验证，不调用 ASR。
- TTS 新请求独立预留名义金额（当前默认 ¥0.10），包括手动重试；同意图重放不再预留，缓存播放零调用。供应商内部最多一次重试沿用原上限，原始尝试数另存；名义预算不冒充真实账单硬上限。翻译和语义检查调用前标记，迟到结果不进学习证据，已发生尝试保守结算。
- 复练语音三入口统一风险门控和录音期限。普通会话风险绑定原题，暂停恢复同题可继续；复练风险还绑定阶梯/队列题版本，状态改变后要求重新录音。旧普通风险缺少题目绑定时不形成新口语证据，可改文字或重录。
- 单句全部阶梯可录音，尝试和录音元数据原子保存。本人文件按录音期限清理，幂等快照同步撤销 URL。独立/换题期间不提供旧参考录音或示范，只允许本阶段本人录音听回；重录先返回上一次帮助阶段，结束后允许对比且不再提交新证据。未增加伪造的词级评分。
- 材料、教学上下文和终态时钟分别共用确定性入口；修订后完整接收详情，原回顾作废与派生按钮同步。计划删除只清本人活动及历史计划，解绑 Session 关联；已有练习、队列及其他用户数据保留。
- 浏览器 44 组宽度及关键操作验证，9 张截图已查看；真实重启保留新录音版本、暂停和风险状态。原库先原生备份，副本迁移两次再更新原服务，原记录数与完整性不变。无密钥匹配，无真实模型调用。原项目仍在 3001/8001，临时服务验收后关闭。
