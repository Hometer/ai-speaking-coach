## 数据、接口与失败处理

- 所有表采用增量迁移，迁移前备份原 SQLite；不清空旧记录。新增操作归属/完成时间、暂停前状态、问卷版本事实等字段或表。历史快照只按真实关联补齐，不猜测缺失用户事实。
- 操作恢复以 user_id、session_id、scope、request_key 定位；只读定位/状态接口不触发供应商。新接口明确请求字段、成功对象及错误；错误继续统一 `{error:{code,message}}`。
- 练习材料缺失返回明确 `MATERIAL_NOT_AVAILABLE`；参考错配返回 `REFERENCE_MISMATCH`；状态改变返回 `STALE_OPERATION`；幂等冲突仍为 409。已有 SSE 继续以 done/error 收尾。
- 反馈材料是可选扩展，旧评估结果继续可读；没有可靠材料时不展示会误导用户的派生内容。材料显示与后端资格判断使用同一事实。
- 产品事件不新增正文或音频副本；问卷历史只保存答案/版本/时间；所有新增记录随所属会话删除与到期清理。

## 实施记录

Q2-01～12 已完成本地实现和反例回归。[逐项验收与截图](../../evidence/阶段3-v0.10第二次质检修复-20261015/验收记录.md)。

- 操作归属与根请求互斥分离；嵌套记录保留 session_id/parent_id。旧关联仅按同用户、原对象和可信快照恢复；无法证明父 ID 标为 legacy，不猜完成时间。删除/争议撤销覆盖嵌套快照。
- 创建意图在发请求前保存首次完整参数，按邀请身份哈希隔离；并发调用合并。恢复原创建先于新预检，避免设备检查 ID 变化导致第二次付费意图。已完成创建、语音、回合和复练均可只读定位；浏览器未确认的意图才登记恢复。
- 统一材料服务验证对应中文意思、适用场景、原句语块及唯一替换位置。同次评估增加可选材料字段，不增加模型调用；材料错误仅丢弃材料，保留有效语言诊断。固定审核材料只做精确句子匹配。旧队列、语块卡和今日任务读取时也重新核对；材料缺失的旧今日任务说明原因并结束，原队列到期时间、次数和历史保持。
- 阶梯控制用 SQL 原子递增版本，避免两个页面持有旧对象而漏增。ASR 风险和业务结果均先核对再写学习内容；请求结束统一收尾预算。已尝试供应商的名义金额保守结算，实际用量/账单保持独立；预算日期在预留时固定。统一截止不能保证供应商停止计费，这项真实风险继续待核对。
- 服务端绑定当前参考句，错配在供应商调用前拒绝；评测保存参考句和内容版本。暂停前状态持久化，新状态精确恢复；旧暂停只按已保存回合事实恢复。
- 问卷保存最小版本历史，修改采用版本条件更新；界面按会话、版本、请求代次接纳响应。历史窗口排除截止后完成、答案和恢复结论，缺少历史时间标未知。带偏移的查询时间先归一到 UTC，避免 SQLite 比较偏差。API 时间统一含偏移，前端兼容旧 UTC 字符串，计划纯日期不变。
