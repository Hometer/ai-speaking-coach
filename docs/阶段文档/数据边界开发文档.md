# 数据边界开发文档（v0.6 · REQ-11/15）

> 依据：PRD v0.6 第 6.11、12.3 节。本阶段补"源建议失效传播 + 删除级联 + 逐条确认"的数据边界。

## 一、阶段目标

让"练这一句"的来源与数据边界闭环：源建议更正/争议/删除后，关联单句复练标"来源失效"；删除源记录时级联清理复制的源文本与派生引用；记忆关闭时严格逐条确认（已随"练这一句"实现，本阶段补传播）。

## 二、数据模型变更

- `Session` 增加 `source_invalid`（Boolean，默认 False）。

## 三、后端方案

1. **争议传播**：`dispute_review_improvement` 标记改进建议 disputed 后，把以该建议为来源的单句复练会话标 `source_invalid=True`。
2. **删除传播**：`delete_session`/`delete_all_sessions` 删除源会话时，把以其为来源的单句复练会话标 `source_invalid=True`，并清空复制来的 `practice_sentence`（保留该会话自身新产生的回答/录音，按自身期限清理）。
3. **失效展示**：会话详情/回顾对 `source_invalid` 的单句复练标明"来源已失效"；前端不再把失效材料当有效建议。
4. **逐条确认**：已实现（练这一句创建前确认框；仅带入选中句，不注入整份旧报告）。

## 四、前端方案

- 单句复练页对来源失效会话展示"来源已失效，建议重新生成"提示。

## 五、测试要求

1. 争议源建议后，关联单句复练 `source_invalid=True`。
2. 删除源会话后，关联单句复练标失效、复制文本清空。
3. 记忆关闭时创建单句复练不注入旧回顾/弱项（已有）。

## 六、验收清单

1. 源建议争议/删除后，关联单句复练不再使用失效材料。
2. 删除源记录级联清理复制文本与派生引用。
