# P1-A 收尾开发文档（转写修订入口 / 提示按钮 / 评价异议）

> 依据：PRD v0.5（REQ-02/05/08）、差距清单 v0.5。补完 P1-A 三个小尾巴。

## 一、阶段目标

补完 P1-A：转写修订前端入口、对话页"给点提示"、回顾"评价有误"标记。

## 二、方案

### 1. 转写修订入口（GAP-09 前端）

- 对话页消息增加 `turn_id`/`input_type`；语音/文字回答气泡提供「修订」。
- 点「修订」→ 内联输入框 → 调 `PATCH /sessions/{id}/turns/{turn_id}` → 显示修订文本，旧评价已置 `revised`。
- 后端已有接口，前端补入口与展示。

### 2. 「给点提示」按钮（GAP-08）

- 新增 `POST /sessions/{id}/hint`：教练立即给出提示（不等待两次失败阈值）。
- Mock 教练：`help_requested` 上下文 → 返回 hint 动作。

### 3. 回顾「评价有误」标记（GAP-12）

- 新增 `POST /sessions/{id}/review/dispute`：按 `turn_id` 把回顾里对应改进建议标 `disputed`。
- 记忆生成跳过 `disputed` 建议；前端回顾每条建议提供「有误」按钮，标记后显示"已标记，待复核"。

## 三、测试要求

1. 提示：`/hint` 返回 hint 动作，不消耗失败阈值。
2. 修订：修订后旧评价置 revised，统计不沿用。
3. 异议：标记后该建议不再进入记忆候选。

## 四、验收清单

1. 对话页能改转写，改后评分作废。
2. 点「给点提示」立即收到提示。
3. 回顾每条建议可标"有误"，标后不用于记忆。
