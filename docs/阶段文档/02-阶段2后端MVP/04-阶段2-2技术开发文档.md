# 阶段 2.2 技术开发文档｜Agent 教练会话 + Harness 约束 + 持久化

> 配套文档：《AI口语练习PRD-v0.1.md》（v0.4）、《Harness架构方案.md》、通用技术栈手册、《技术适配声明》、阶段 2.1 文档。
> 本文档只覆盖阶段 2.2。阶段 2.3（练习回顾/历史/记忆/达标验证）、阶段 3（正式前端）不在本阶段实现。

## 一、阶段目标

- 交付范围：把阶段 2.1 的"一问一答"升级为**有目标的会话 Agent**——会话状态机、SQLite 持久化（重启可恢复）、Agent 教练按表现选择教学行动、独立评估器（与生成分离）、Harness 约束（工具次数/预算/停止规则）、短句跟读评测、SSE 流式回合。
- 阶段产物：
  1. SQLite 数据模型（users / sessions / turns / evaluations）+ 持久化；
  2. 会话状态机与生命周期 API（创建会话、语音/文字回合、跟读评测、结束）；
  3. Agent 教练决策（LLM 结构化输出 + mock）；
  4. 独立评估器（四态：独立完成/提示下完成/未完成/证据不足，与生成分离）；
  5. Harness 约束：单回合 Agent 工具 ≤3 次、工具重试 ≤1、会话/用户/项目预算、停止规则；
  6. 跟读评测（示范 + 用户录音 + 评测，评测 mock，真实讯飞待验）；
  7. 回合 SSE 流式（chunk → done/error）；
  8. 扩展最小验收页：开始会话、多轮对话、触发跟读、结束并查看会话摘要。
- 验收标准：mock 测试全部通过；最小界面可走通"开始 → 多轮对话 → 跟读 → 复测 → 结束"；真实模型冒烟待验（无 Key）。
- 明确不做：练习回顾的"最多 3 条改进建议"报告（2.3）、历史页与删除（2.3）、学习记忆读写（默认关闭，2.3）、正式前端视觉（3）、讯飞/百炼真实接入（有 Key 后冒烟）。
- 主链路片段：**开始会话（目标+首问）→ 多轮回合（Agent 决策）→ 独立评估 → 跟读 → 复测 → 结束**。

## 二、技术适配摘要

- 开发路径：纵向切片（延续）。
- 采用默认方案：Python 3.12 + FastAPI + Pydantic + pytest + SQLAlchemy + SQLite。
- 启用按需模块：SQLite + SQLAlchemy（多实体关系、用户账户、历史查询触发）；SSE（流式回合）。
- 偏离/暂缓：Alembic 迁移暂缓（本阶段用 `create_all()` 建初版 schema，schema 稳定后、上线前引入 Alembic）；发音评测用 mock provider（真实讯飞接入待验）。

## 三、技术栈与模型

- 组件：FastAPI、SQLAlchemy、SQLite、pydantic、python-dotenv、pytest、httpx、dashscope（骨架）。
- 模型：主模型通义千问（qwen-plus）承担"教练决策"与"独立评估"两路请求；评估与生成分离，不强制第二位 Agent。发音评测候选科大讯飞英文短句评测。均 mock 先行、真实待验。

## 四、环境与配置

## 六、数据、资产与状态

- 持久化：SQLite（`data/ai_speaking.db`，gitignore 已排除），进程重启可恢复。
- 表结构：
  - `users`：id、level、created_at。
  - `sessions`：id、user_id、status、goal_text、difficulty、end_reason、started_at、ended_at。
  - `turns`：id、session_id、seq、input_type（voice/text/practice）、transcript、user_text、reply_text、reply_audio_url、action_type、hint_used、practice_sentence、eval_result、created_at。
  - `evaluations`：id、session_id、turn_id、result、evidence_turn_ids、standard_version、created_at。
  - `budget_ledger`：id、scope（session/user/project）、scope_key、reserved、spent、updated_at。
- 资产：录音 `data/uploads/`、合成音频 `data/audio/`（沿用 2.1），路径受控；录音清理规则在 2.3 完善。
- 状态机（PRD 9.2，Harness 维护，模型不可改写）：
  `PREPARING → WAITING_INPUT ⇄ PROCESSING → TEACHING_FEEDBACK →（PRACTICE → RECHECK）→ ENDED`；`PAUSED` 由用户暂停/恢复，期间不录音、不产生教学动作。

## 七、API / 工具设计

统一错误 `{"error":{"code","message"}}`。身份由 `X-User-Id` 头注入（缺省 demo-user），后端校验，模型不可自填。

| 接口 | 方法/路径 | 说明 |
| --- | --- | --- |
| 创建会话 | POST `/api/v1/sessions` | `{level, difficulty}` → 生成目标+首问，状态 WAITING_INPUT，返回 `{session_id, goal_text, reply_text, reply_audio_url}` |
| 语音回合 | POST `/api/v1/sessions/{id}/turns/voice` | 上传音频 → ASR → 决策/评估 → 落库，SSE 返回 |
| 文字回合 | POST `/api/v1/sessions/{id}/turns/text` | `{text}`，同上（无 ASR） |
| 跟读评测 | POST `/api/v1/sessions/{id}/practice` | `{audio, sentence}` → 评测，状态 PRACTICE→RECHECK |
| 结束会话 | POST `/api/v1/sessions/{id}/end` | `{reason}` → ENDED + 会话摘要 |
| 会话详情 | GET `/api/v1/sessions/{id}` | 状态 + 回合列表（限本人） |

SSE 事件约定（普通回合）：`chunk`（回复文本，零到多次）→ `done`（含完整结果 `{turn_id, transcript, reply_text, reply_audio_url, action_type, eval_result, status}`）；失败以 `error` 事件返回统一错误结构。跟读评测为同步接口（P95≤8s 目标，2.3 达标测量）。

Harness 约束：单回合 Agent 自主工具调用 ≤3 次、工具自动重试 ≤1；预算原子扣占（会话 ¥3 含结束预留 ¥0.30、用户日 ¥10、项目日 ¥100）；停止规则（用户结束/目标达成/预算或工具上限/2 次教学调整未完成则降难度或结束）。

## 八、Prompt 设计

- 教练系统提示词（`prompts/coach.py` 升级到 v2）：在原 v1 基础上增加——输出**结构化 JSON**（`action_type` ∈ follow_up/hint/suggest_practice/recheck/finish、`reply_text`、可选 `follow_up_question`/`practice_sentence`/`needs_evaluation`），明确"你只负责教学，不宣告完成，完成由评估器判断"；附正反例与禁止格式。
- 独立评估提示词：输入目标、用户回答、提示使用、工具结果、标准版本；输出四态之一 + 证据回合引用；禁止用教学回复中的"很好"作为完成证据。

## 九、验收界面或纵向切片

扩展 2.1 的 `index.html`：开始会话（选难度）→ 目标与首问展示 → 多轮语音/文字 → 接受跟读（示范+录音+评测展示）→ 复测 → 结束并展示会话摘要。仍为临时验收工具，非正式产品切片。

## 十、测试要求（mock，离线必跑）

1. 会话创建：状态 PREPARING→WAITING_INPUT，返回目标+首问。
2. 状态流转：正常回合、进入跟读、复测、结束；非法状态操作被拒。
3. 独立评估器四态：无提示覆盖要点=独立；有提示=提示下；未答/证据不足=证据不足/未完成。
4. 教练决策结构校验：非法 JSON/缺字段 → 走统一错误或有限重试。
5. Harness：单回合工具 >3 次被拒；预算超限拒绝并说明原因；跨用户访问会话被拒。
6. 持久化：会话/回合落库，重启（重建 session）后仍可读。
7. SSE：事件序列 chunk→done；失败以 error 收尾且结构统一。
8. 跟读评测：返回评测结果（mock）；证据不足不评分。

## 十一、验收清单（产品经理照着点）

1. 打开 `http://127.0.0.1:8000/`，点「开始会话」（选难度）。
2. 看到目标 + 一句面试官首问（可播放）。
3. 用文字回答，看到面试官接着追问（多轮）。
4. 点「跟读」（如出现），看到示范句、录音、评测结果，返回后可复测。
5. 点「结束」，看到会话摘要（目标状态、轮数、评估结果）。
