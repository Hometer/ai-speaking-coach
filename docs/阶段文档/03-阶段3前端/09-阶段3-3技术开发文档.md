# 阶段 3-3 技术开发文档｜后端真实接入（语音识别 + 讯飞发音评测）

> 依据：PRD v0.4 第 10.6 节、阶段 2.1~2.3 文档、真实冒烟结论。本文档只覆盖"后端真实接入"这一件事，不涉及前端新页面。

## 一、阶段目标

把最后两处 mock/待验的能力接成真实，让"真语音 → 真转写 → 真 AI 回复 → 真跟读打分"全链路跑通：

1. **语音识别（ASR）**：浏览器录音 → 后端转码 → 阿里云百炼 paraformer 转写为文字（当前为 mock 固定句）。
2. **发音评测（讯飞）**：跟读录音 → 讯飞英文短句评测 → 返回真实评分（当前为 mock 固定分）。

阶段产物：可用的 ASR 真实 provider、讯飞评测真实 provider、音频转码工具、真实模式整体联调通过。

## 二、技术适配摘要

- 沿用：FastAPI + provider 抽象（asr.py / practice.py 的 mock 与真实骨架已就绪）。
- 新增依赖：`ffmpeg`（系统级，用于音频转码）。
- 真实模型：ASR 用阿里云百炼 `paraformer-realtime-v2`（本地文件识别）；评测用讯飞英文短句评测。

## 三、技术方案

### 3.1 音频转码（关键前提）

浏览器 MediaRecorder 产出 webm/mp4/ogg（容器 + opus/aac），而百炼 ASR 与讯飞评测都需要 **PCM/WAV 16kHz 单声道**。因此后端加一个转码工具：

- 用系统 `ffmpeg` 把任意容器格式转成 `wav`（16kHz、单声道、16bit）。
- 转码失败 → 按 PRD 10.3 降级：提示重录或改文字，不评价失败录音。

### 3.2 语音识别（ASR）

- 方案：`dashscope.audio.asr.Recognition`（paraformer-realtime-v2），`call(file=本地wav)` 同步返回转写。
- 参数：`model="paraformer-realtime-v2"`、`format="wav"`、`sample_rate=16000`。
- 置信度/失败：识别为空或异常时，走统一错误 + 提示重录/文字（PRD 10.3）。

### 3.3 讯飞发音评测

- 方案：讯飞开放平台英文评测 HTTP API（`ise-api.xfyun.cn`），用 APPID + APIKey + APISecret 鉴权。
- 输入：参考文本 + base64 PCM（16k 单声道）。
- 输出：服务支持的评分维度（词/短语级），证据不足不评分。
- 三件套已就绪：`XF_APPID`、`XF_API_KEY`、`XF_API_SECRET`（在 `.env`，不入库）。

## 四、环境与配置

- 新增系统依赖：`ffmpeg`（`brew install ffmpeg`）。
- 新增配置：`FFMPEG_BIN`（默认 `ffmpeg`）、讯飞三件套读取。
- `PROVIDER_MODE=real` 时启用真实 ASR/评测；mock 模式行为不变。

## 五、项目结构（新增/变更）

```text
backend/app/services/
├── audio_util.py    # 新增：ffmpeg 转码（webm/mp4/ogg → wav/pcm 16k mono）
├── asr.py           # 变更：DashScopeASRProvider 改为 Recognition 真实实现

```

## 六、API / 状态

- 接口不变（`/turns/voice`、`/practice`、`/audio/{filename}`），前端零改动。
- 语音回合：录音上传 → 转码 → ASR → 教练决策 → TTS（真实链路）。

## 七、测试要求

1. mock 测试保持全绿（provider 抽象不变）。
2. 真实冒烟（有 Key）：
   - 一条真录音 → ASR 转写 → LLM 回复 → TTS 播放；
   - 一条跟读录音 → 讯飞评分返回。
3. 转码失败/识别失败/评测失败 → 统一错误结构 + 可重试，不崩溃。

## 八、验收清单（产品经理照着点）

1. 后端切到真实模式后，电脑浏览器录音说一句英文 → 出现**真实的转写文字**（不是固定句）。
2. AI 回复是**真实生成的**（会针对你说的内容回话），语音是**真实英文女声**。
3. 跟读一句 → 看到**真实的评测分数**。

## 九、风险与回退

- ffmpeg 安装失败 → 回退：mock ASR/评测，文字链路仍真实。
- 讯飞鉴权/参数复杂 → 按官方文档核对，超时/失败走降级。
- 真实时延/成本 → 本阶段只跑通，达标测量在后续（PRD 10.4/10.5）。
