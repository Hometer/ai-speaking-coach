# 阶段 3-4 前端开发文档（回顾 / 历史 / 记忆 + 录音计时）

> 前端内部子阶段 3：Agent 完整交互。依据《前端技术适配声明》、PRD 第 6.5/6.7/6.8/9.3 节、后端已有接口（阶段 2.3 已实现）。

## 1. 本阶段目标

用户完成一段练习后，能：看到练习回顾；回看/删除历史记录；开关并管理学习记忆；录音时有 60 秒上限与倒计时提示。

## 2. 范围

### 本阶段包含

- 对话页补强：录音计时（0~60s、剩 10 秒提示、60s 自动结束提交）、取消录音不提交、播放停止按钮；
- 回顾展示：结束练习后展示回顾报告（目标结果、改进建议、评价、下次建议）——复用已有 review 接口，完善展示；
- 历史页：列表（日期/结果/轮数）→ 详情（对话文本 + 回顾）→ 删除；
- 记忆面板：开关（默认关）、候选列表、清空/单删；
- 全局导航：首页 / 历史 / 记忆。

### 本阶段不包含

- 真实登录/邀请码（阶段 4）；
- 部署上线（阶段 4）。

## 3. 用户流程

1. 对话页录音 → 显示已录秒数；剩 10 秒提示；到 60 秒自动停止提交；可取消不提交。
2. 结束练习 → 看到回顾报告。
3. 顶部「历史」→ 看到练习列表 → 点进详情看对话和回顾 → 可删除。
4. 顶部「记忆」→ 默认关闭 → 开启后（此前结束过的练习会生成候选记忆）→ 查看/清空。

## 5. 接口契约（后端已就绪）

- `GET /api/v1/sessions`（列表，X-User-Id 鉴权）
- `GET /api/v1/sessions/{id}`（详情含 review + turns）
- `DELETE /api/v1/sessions/{id}`（删除）
- `POST /api/v1/sessions/{id}/end`（返回 summary + review）
- `POST /api/v1/users/me/memory`（`{enabled}`）
- `GET /api/v1/users/me/memories`
- `DELETE /api/v1/users/me/memories/{id}`、`DELETE /api/v1/users/me/memories`
- 统一错误 `{"error":{"code","message"}}`

## 6. 实现方案

- 路由：`/`（首页）、`/practice/[sessionId]`（对话页）、`/history`（历史）、`/memory`（记忆）。
- 组件：`RecordButton`（含计时）、`ReviewCard`、`NavBar`、`SessionList`、`MemoryPanel`。
- `lib/api.ts` 扩展：listSessions / deleteSession / getMemories / toggleMemory / clearMemory / deleteMemory。
- 录音计时：`setInterval` 每 1s 更新；`MediaRecorder` 到 60s 自动 `stop()`；取消按钮丢弃 blob 不提交。
- 响应式：Tailwind 移动优先，桌面两列 / 移动单列，375px 可用。
- 安全：Key 只在后端；前端不存音频、不出现密钥。

## 7. 验收标准

- 自动检查：`npm run lint`、`npm run typecheck`、`npm run build` 通过。
- 人工检查（桌面 + 移动 375px）：录音倒计时、60s 自动停、取消不提交、回顾展示、历史增删、记忆开关/清空。
- 截图：回顾页、历史页、记忆页（桌面 + 移动）。

## 8. 风险与回退

- 录音计时依赖浏览器 `setInterval`，到 60s 强停；异常时保留文字入口。
- 历史/记忆依赖后端 mock 数据（回顾措辞为模板），真实效果随后端切真实模式自然升级。
