# 阶段 3-2 前端开发文档（可运行骨架 + 第一条真实闭环）

> 前端内部子阶段 1+2 合并（此前未搭建前端工程，骨架与第一条闭环一起做）。依据《前端技术适配声明》。

## 1. 本阶段目标

用户打开正式前端，能"开始一段面试自我介绍练习，并完成至少一轮对话"：打字或录音 → 看到自己的转写/文字、AI 的回复与可播放语音；桌面与移动端布局正确。

## 2. 范围

### 本阶段包含

- Next.js App Router + TypeScript strict + Tailwind CSS 工程骨架；
- 语义化设计变量（参考流利说/Duolingo 对话练习页：暖色主色、圆角卡片、左右气泡、大麦克风按钮）；
- 通用组件：Button、Card、RecordButton（MediaRecorder）、AudioPlayer、StatusBadge、MessageList、EmptyState/LoadingState；
- 集中式 API 客户端 + SSE 解析（chunk/done/error）；
- 页面：首页（开始练习入口）+ 对话页（目标、消息流、录音/文字、跟读面板、结束）；
- 真实后端对接：文字回合走真实 qwen-plus + cosyvoice-v2/loongabby_v2 TTS；语音回合录音上传（ASR 待接入，暂 mock 转写）；跟读评测暂 mock（讯飞三件套已齐，接入留后续）。

### 本阶段不包含

- 回顾页/历史页/记忆页（前端子阶段 3）；
- 讯飞发音评测真实接入（子阶段 3）；
- 真实登录/邀请码、部署上线（阶段 4）。

## 3. 用户流程

1. 首页 → 选难度 → 点「开始练习」。
2. 对话页 → 看到本次目标与面试官首问（可播放）。
3. 打字或录音回答 → 看到自己的输入 + AI 回复 + 可播放语音。
4. 可继续下一轮，或点「结束练习」（占位，回顾在子阶段 3）。

## 5. 接口契约

- `POST /api/v1/sessions` → `{session_id, goal_text, reply_text, reply_audio_url, status}`；
- `POST /api/v1/sessions/{id}/turns/text`（SSE）→ `chunk`* + `done`（含 `turn_id/transcript/reply_text/reply_audio_url/action_type/eval_result/status/practice_sentence`）或 `error`；
- `POST /api/v1/sessions/{id}/turns/voice`（SSE，multipart）；
- `POST /api/v1/sessions/{id}/practice`（multipart + sentence）；
- `POST /api/v1/sessions/{id}/end` → `{summary, review}`；
- 统一错误 `{"error":{"code","message"}}`。

真实/mock 切换：后端 `PROVIDER_MODE` 控制，前端不改代码；前端 `next.config` 用 `rewrites` 把 `/api/*` 代理到 `http://127.0.0.1:8000`。

## 6. 实现方案

- 路由：`/`（首页）、`/practice/[sessionId]`（对话页）。
- 组件：`components/`（Button/Card/RecordButton/AudioPlayer/StatusBadge/MessageList）；`lib/api.ts`（fetch + SSE）；`lib/types.ts`（后端类型）。
- 状态：会话状态以后端为准；`sessionId` 存 `localStorage` 用于刷新恢复。
- 流式：回合用 `fetch` + ReadableStream 解析 SSE。
- 响应式：Tailwind 移动优先，桌面两列/移动单列，375px 可用。
- 安全：Key 只在后端；前端不存音频、不出现任何密钥。

## 7. 验收标准

- 自动检查：`npm run lint`、`npm run typecheck`、`npm run build` 通过。
- 浏览器人工检查：桌面 Chrome/Safari 与移动 375px 各走一遍第 3 节流程。
- 真实联调：文字回合走真实 qwen-plus + TTS，能听到 AI 语音。
- 截图：桌面 + 移动端代表页。

## 8. 风险与回退

- ASR 未接入：语音回合转写为 mock 标记，文字回合已真实；ASR 接入（转码方案）作为后续重点。
- SSE 兼容性：解析器做 done/error 兜底，异常提示重试。
- 回退：如真实后端有问题，前端可切回 mock（`PROVIDER_MODE=mock`），接口契约不变。
