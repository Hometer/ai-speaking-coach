## 2. P1 范围与不做（REQ-32 ~ REQ-34）

### 2.1 P1 做

1. **REQ-32 识别不确定性保护**：语音回合增加低/中/高三档风险判定（确定性规则），高风险先让用户核对再评价。
2. **REQ-33 水平与挑战分离**：教练语言复杂度由"水平"控制，情境阻力由"简单/标准难度"控制；两套参数独立传入。
3. **REQ-34 对话节奏与回应质检**：教练先接住用户真实意图（尤其直接提问），连续追问必须利用新信息，子目标推进仍由独立评估器裁决。

### 2.2 P1 不做

- 跟读文本对照、视频到 AI 话题、原创配音微场景、FSRS 生词本、网盘导入、会员、自带 Key、Live2D（均为候选）。
- 不新增 ASR 供应商；识别风险不另发模型请求。
- 不新增"情绪识别"结论。
- 不改变七场景、待复练、脱稿阶梯、语块卡、进步中心的既有口径；只在其上叠加保护与质检。

## 3. 现状与差距

| 需求 | 现状 | 差距 |
| --- | --- | --- |
| REQ-32 | 语音→转写→直接进评估/教练，无"识别可靠性"判断；有转写修订（REQ-02）但只靠用户主动改 | 没有空转写/截断/噪声的确定性风险分级；可疑转写会被当成语言错误、写进纠错与独立完成证据 |
| REQ-33 | 已有 beginner/basic/intermediate 三水平，场景有难度概念；教练 Prompt 混在一起 | 水平与难度语义未分离；"标准"可能被模型理解成换更难生词，而非换任务阻力；两档共用目标与判定未显式固化 |
| REQ-34 | 教练 Prompt 已修 v5（先答反问、去示例泄露），但「What about you?」仍有残留；评估器逐回合一子目标 | 无"直接提问→必答→至多一追问"的确定性信号与质检记录；无连续同义追问/突兀换题的质检标记 |

## 4. 数据模型

### 4.1 新增 `AsrRiskRecord`（识别风险记录）

```text
AsrRiskRecord
  id                自增主键
  user_id           归属用户
  session_id        所属会话
  turn_id           关联语音回合（一个回合至多一条，幂等）
  risk_level        low | mid | high
  reason_code       规则原因码（empty / noise / truncated / repeated / garbage 等，可多值）
  original_text     原转写（脱敏；随会话文本到期）
  confirmed_text    用户确认或修订后的文本（未确认时为空）
  action            none | confirm | rerecord | revise | text_fallback
  asr_rule_version  确定性规则版本号
  created_at / resolved_at
```

### 4.2 新增 `ConversationQualityMark`（对话质检标记）

```text
ConversationQualityMark
  id                自增主键
  user_id / session_id / turn_id
  user_direct_question    bool（是否包含用户直接提问，确定性信号提示）
  user_ask_explanation    bool
  user_gave_info          bool
  coach_action            answered | clarified | follow_up | help | transfer | suggest（教练动作类型）
  repeated_synonym_followup bool（连续同义追问）
  topic_jump             bool（是否发生突兀话题跳转）
  subgoal_id            当前子目标
  prompt_version / scenario_version
  created_at
```

不复制用户完整正文；技术日志只记上述结构信号，沿用既有脱敏与权限规则。

### 4.3 现有字段扩展

- `Turn` 增加 `risk_level`（冗余便于查询）与 `asr_risk_id` 关联；`Session` 增加 `difficulty`（simple | standard，创建时固定）、`level` 沿用现有水平字段。
- 难度与水平均为会话创建时固定，切换难度不重置到期时间、复练历史、预算（PRD 6.14）。

## 5. 后端设计

### 5.1 REQ-32 识别不确定性保护

**风险判定（确定性，不新增模型调用）**

语音转写返回后，在进入评估/教练前执行 `asr_risk_svc`：

- 低风险：正常流程。
- 中风险：保留可修改转写 + 轻提示，允许用户直接确认。
- 高风险：暂停该回答的语言评价、教练推进、发音结论、独立完成写回；提供"听回 / 重录 / 修订 / 改用文字"四操作；无录音可回放时说明原因。

规则信号（先做确定性规则，规则要豁免短而有效的回答，单词少本身不是错误）：

| 信号 | 判定 | 说明 |
| --- | --- | --- |
| 空转写 | 高 | 无内容可评价 |
| 明显噪声/乱码 | 高 | 非语言内容 |
| 疑似句尾截断 | 中/高 | 按结尾形态与置信度判定 |
| 异常重复 | 中 | 同词连续重复超出合理范围 |
| 短而正确回答 | 低（豁免） | "Yes, please." 类不拦截，样本记录误拦截 |

供应商返回可信置信度时作为辅助信号，不单凭一个分数覆盖用户文本或生成发音问题。

**确认与失效传播**

- 用户确认原转写或提交修订后，才继续同一题；评价只基于确认后的有效内容。
- 修订沿用 REQ-02 失效传播：旧评价、回顾、语块卡、待复练来源同步失效；过期录音不为新评价提供证据。
- 重复提交不创建双回合、不重复计费（幂等标识沿用现有回合去重）。
- 用户未确认而退出，不记学习失败。

**边界**

- 纯文字回答不适用风险判定。
- 风险等级不是识别准确率、不是能力分数；界面不得声称"你说错了"。
- 第一版不因风险判断另发模型请求；真实样例发现误拦截后调整规则并记录版本。

### 5.2 REQ-33 水平与挑战分离

**教练 Prompt 改造**：把"用户英语水平"与"任务挑战档位"拆成两个独立输入。

| 输入 | 控制什么 | 不允许 |
| --- | --- | --- |
| `level`（入门/基础/中级） | 用词、句长、语速、必要解释；两档难度下保持相近语言复杂度 | 用更难生词/长句充当"标准" |
| `difficulty`（简单/标准） | 角色配合度、澄清、追问深度 | 虚构政策、故意刁难、连续多问、改掌握门槛 |

- 简单：角色更配合，优先接受清楚的合理表达，卡住时适当简化。
- 标准：角色在场景内提出合理澄清、条件变化或一项相关追问。
- 两档共用同一场景小目标、帮助证据、独立完成判定；切换难度不重置到期时间/复练历史/预算。

**会话固定**：`difficulty` 在会话创建时写入并固定，进行中不改；下一次练习可重新选择。前端准备区明确说明"水平控制什么、难度控制什么"。

### 5.3 REQ-34 对话节奏与回应质检

**教练决策优先级（Prompt + 确定性信号）**

1. 先处理用户本回合真正发出的请求（直接提问 / 请求解释 / 给出信息）。
2. 用户直接问角色时，先用具经审核角色事实回答；事实不足用不捏造的说法说明边界，再至多追加一个相关问题。不得为推进子目标跳过用户的问题。
3. 对同一小目标连续追问，下一问须利用用户新信息或合理澄清；不得连续输出换词不换意的问题。
4. 用户卡住时先使用现有四类求助或简化问题能力。
5. 只有独立评估器确认满足子目标标准后才更新完成证据；教练不得自行宣告掌握、改目标或把状态摘要当评价事实。

**确定性信号（辅助模型，不替代文本理解）**

- 问号不一律解释为困惑，模型必须结合文本判断。
- 记录 `ConversationQualityMark` 最小结构信号（是否直接提问、是否作答、动作类型、连续同义追问、话题跳转）。

**质检**：审核界面沿用既有脱敏与权限规则，新增"识别风险"与"对话回应"标记筛选。

## 6. 前端设计

- **对话页**：语音提交后若为高/中风险，展示核对卡——原转写 + "听回 / 重录 / 修订 / 改用文字"，确认后才继续；低风险无感知。
- **准备区**：水平与难度分开展示，各自标注"控制什么"（水平=语言难易，难度=情境阻力）。
- **内部质检页**：样本列表增加风险等级、直接提问应答、连续同义追问、话题跳转标签，可筛选。

## 7. 验收标准（AC09-01 ~ AC09-12）

| 用例 | 可观察通过条件 |
| --- | --- |
| AC09-01 | 静音/噪声/截断转写标为高风险时页面提示核对；未确认前不生成纠错、独立完成或掌握证据 |
| AC09-02 | "Yes, please." 等短而有效回答不因字数少被拦截；规则样本记录误拦截 |
| AC09-03 | 用户确认/重录/修订后按新来源版本重评价，旧反馈及复练来源失效 |
| AC09-04 | 中途退出/识别失败/重复提交不制造学习失败、重复队列或重复计费；录音按原规则删除 |
| AC09-05 | 同水平切换简单/标准，英语词句保持该水平可懂，挑战变化来自角色配合度与任务条件 |
| AC09-06 | 标准档出现合理澄清/追问、简单档更配合；两档均不捏造用户身份/经历/场景事实 |
| AC09-07 | 难度切换不改变独立完成/掌握/发音证据/预算规则；进行中会话设置固定 |
| AC09-08 | 每次回应只推进一个主要问题；角色不凭空加规则或声称真实个人经历 |
| AC09-09 | 用户问 "What about you?" 等直接问题先回应其意图，再自然推进场景，不用固定套话回避 |
| AC09-10 | 连续追问使用用户刚提供的信息，必要时给帮助；不重复同一问法或突然跳题 |
| AC09-11 | 子目标仅确定性评价满足后推进；模型猜测的用户情绪不写入事实记忆 |
| AC09-12 | 七场景真实样例按第 13 节抽查并记录分母/争议/失败；质量门槛不低于既有基线，未完成标待验 |
