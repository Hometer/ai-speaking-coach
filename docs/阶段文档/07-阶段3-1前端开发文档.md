# 阶段 3-1 前端开发文档（可运行骨架 + 代表页）

> 前端内部子阶段 1，对应《前端技术适配声明》。本阶段只做骨架 + 一个代表页闭环，不铺全站。

## 1. 本阶段目标

用户能在正式前端里"开始一段练习，并完成第一轮语音/文字对话"：录音或打字 → 看到转写与 AI 回复 → 播放 AI 语音；桌面和移动端布局正确。

## 2. 范围

### 本阶段包含

- 工程：Next.js App Router + TypeScript strict + Tailwind CSS + 语义化设计变量；
- 布局/导航：顶部导航（开始练习 / 历史 / 记忆占位）、页面容器；
- 通用组件：按钮、卡片、录音按钮（MediaRecorder）、音频播放器、状态徽标、空/错/加载态；
- API 客户端：集中式 `apiClient` + SSE 解析（`chunk/done/error`）；
- 代表页：首页（开始练习入口）+ 对话页（目标、消息流、录音/文字输入、结束入口）；
- 工程底线：`lint / typecheck / test / build` 四件套可用。

### 本阶段不包含

- 回顾页、历史页、记忆面板（后续子阶段）；
- 真实登录/邀请码（阶段 4）；
- 部署上线（阶段 4）。

## 3. 用户流程

1. 打开首页 → 看到"面试自我介绍"入口 → 选难度 → 开始。
2. 进入对话页 → 看到目标与面试官首问 → 录音或打字回答。
3. 看到自己的转写/文字、AI 的回复文字与可播放语音 → 可继续下一轮或结束（占位）。

## 4. 页面状态矩阵

| 首页 | 显示入口 | — | — | 点开始后加载会话 | — | 进入对话页 | 创建失败提示+重试 | — |
| 对话页-消息 | 首问 | 会话加载 | 无消息时首问占位 | — | — | 新消息追加 | 请求失败提示 | 会话 ID 恢复 |

## 5. 接口契约

- `POST /api/v1/sessions`（创建会话）→ `{session_id, goal_text, reply_text, reply_audio_url, status}`；
- `POST /api/v1/sessions/{id}/turns/text`（SSE）→ `chunk` 零到多次 + `done`（含 `turn_id/transcript/reply_text/reply_audio_url/action_type/eval_result/status`）或 `error`；
- `POST /api/v1/sessions/{id}/turns/voice`（SSE，multipart 音频）；
- `GET /api/v1/audio/{filename}`（播放音频）；
- 统一错误 `{"error":{"code","message"}}`。

Mock 与真实切换：由后端 `PROVIDER_MODE` 控制，前端不改代码；前端本地用 `next.config` 的 `rewrites` 把 `/api/*` 代理到 `http://127.0.0.1:8000`。

## 6. 实现方案

- 路由：`/`（首页）、`/practice/[sessionId]`（对话页）。
- 组件结构：`app/layout.tsx`、`app/page.tsx`、`app/practice/[sessionId]/page.tsx`；`components/`（Button/Card/RecordButton/AudioPlayer/StatusBadge/MessageList）；`lib/api.ts`（API 客户端 + SSE）；`lib/types.ts`（后端类型）。
- 状态来源：会话状态以后端返回为准，前端只做展示；会话 ID 存 `localStorage` 用于刷新恢复。
- 流式/轮询：回合用 SSE（`fetch` + ReadableStream 解析）。
- 响应式：Tailwind 移动优先，桌面两列、移动单列；375px 可用。
- 安全和隐私：Key 一律在后端，前端不出现任何密钥；录音只在内存与上传，前端不持久化音频。

## 7. 验收标准

- 自动检查：`npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 全部通过。
- 浏览器人工检查：桌面 Chrome/Safari 与移动端 375px 宽度各走一遍第 3 节流程。
- 真实联调：后端跑通（mock 或真实均可），首页 → 对话页 → 一轮回答 → 播放成功。
- 截图：桌面 + 移动端关键页面。

## 8. 风险与回退

- 风险：SSE 在部分浏览器/代理下兼容性 → 解析器做 `done/error` 兜底，异常时提示重试。
- 风险：麦克风授权被拒 → 降级文字输入（PRD 10.3）。
- 回退：若真实模型冒烟发现问题，前端可继续用 mock 后端，接口契约不变。
