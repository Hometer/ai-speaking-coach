# 阶段 3.5：学习空间视觉完善

2026-09-21。依据：用户本轮授权、PRD v0.6 第 6、14 节、既有前端适配声明、前端手册。

## 视觉适配与范围

参考 [Speak](https://www.speak.com/) 的大标题、圆角和清晰主行动，以及 [ELSA](https://elsaspeak.com/en) 的学习内容分区。仅借鉴布局语言，图标和装饰自行实现，不复制品牌、插画或商业字体。

选用奶油白背景、森林绿主色、浅苔绿卡片、低饱和黄绿装饰。系统中文字体；桌面左侧导航，手机顶部紧凑导航。改进首页准备与设置、对话/跟读/回顾、历史列表/详情、记忆设置/空状态。

继续使用 Next.js 16 / React 19 / Tailwind 4，不增加组件框架。共享样式在 `frontend/app/globals.css`，页面专属样式与页面同目录，共享图标在 `frontend/components`。API 请求仍位于 `frontend/lib/api.ts`。不新增训练场景，不展示虚构练习统计。

## 本批实现

- 首页：场景主卡、练习目标、按水平切换的开场示例、三档水平/独立难度/时长选择、邀请凭证验证、提示展开。
- 练习页：教练与用户对话、语音加载与失败文案、分类求助面板、跟读卡、暂停/继续、录音计时、结束只读及建议复练入口。
- 回顾恢复：刷新恢复双方消息、修订入口和已保存回顾；文本提交失败保留输入；离开页面释放录音资源。
- 历史：实际记录统计、日期/难度/轮次/状态、详情、普通复练和删除确认。未生成虚构统计。
- 记忆：真实设置开关、候选状态与依据数、空状态、删除确认与说明。
- 为修复开关刷新显示错误，新增 `GET /api/v1/users/me/memory`，请求使用现有 `X-Invite-Code`，返回 `MemorySettingsResponse { enabled: boolean }`，错误沿用统一结构；保持原 POST 接口兼容。实现位于原后端路由/Schema，前端调用位于 `lib/api.ts`，身份隔离与持久化读取回归位于 `backend/tests/test_history.py`。
