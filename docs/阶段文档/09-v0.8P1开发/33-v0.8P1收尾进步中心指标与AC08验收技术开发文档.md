## 1. 范围

1. 进步中心新增两个事实指标：**脱稿完成数**、**迁移成功数**。
2. 补 AC08-01 ~ AC08-18 验收清单（逐条对照实现与测试状态）。
3. 补新流程的事件记录（脱稿阶梯、今日复练、语块卡），沿用 EventLog，事件按用户/会话/回合去重。

### 1.1 不做

- 能力量表 / 四维分数（PRD 明确不展示伪精确分数）。
- 公开排行榜、连续登录等（非目标）。

## 2. 现状与差距

- 现状：`progress.py` 已返回 6 个事实指标（完成练习数、独立完成率、帮助使用率、到期复练完成率、已掌握数、语音可评估率）；`DrillAttempt` / `DailyReviewAttempt` / `PhraseCard` 已随 P1-1~4 落库。
- 差距：进步中心没有脱稿/迁移指标；没有 AC08 逐条验收清单；新流程没有 EventLog 事件。

## 3. 数据来源

- **脱稿完成数**：`DrillAttempt.result == "independent"` 的去重次数（每次脱稿说成功计 1）。
- **迁移成功数**：`DrillAttempt.result == "transfer"` 的次数（每次换题成功计 1）。

两者均可从现有 `DrillAttempt` 表确定性聚合，不需要新表。

## 4. 后端设计

1. `get_progress` 增加 `drill_completed_count`、`transfer_completed_count`，并递增 `calc_version`。
2. `GET /api/v1/progress` 响应新增这两个字段；前端进步中心页展示。
3. 事件记录：`drill_svc.submit_drill_attempt` / `daily_review_svc` / `phrase_card_svc` 各写入 EventLog（`action_type` 分别用 `drill` / `daily_review` / `phrase_card`），只记必要标识与结果，不记正文/音频/密钥。

## 5. 前端设计

- 进步中心页新增两张事实卡：脱稿完成数、迁移成功数（同现有指标样式，附口径说明）。
