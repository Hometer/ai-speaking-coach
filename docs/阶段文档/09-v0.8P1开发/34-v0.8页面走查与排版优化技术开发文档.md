## 1. 本阶段目标

在不扩大 v0.8 产品范围的前提下，跑通现有代码并修复浏览器走查发现的漏实现与排版问题，让 P1 新页面与既有学习空间保持一致。

## 2. 本阶段包含

1. 重新执行后端 Mock、前端类型检查、Lint 和生产构建。
2. 浏览器检查首页、今日复练、待复练、语块卡、进步中心的桌面和手机布局。
3. 修复手机顶部导航被八个入口挤压成竖排、末项被截断的问题。
4. 统一今日复练和语块卡的页面标题、加载、空、失败、成功和操作区层级。
5. 补齐语块卡页在 REQ-31 已明确的「练这一句」「加入待复练」入口，复用现有接口，不新建业务链路。
6. 调整进步中心八项指标的网格，让宽屏和手机上保持完整、均衡。

## 3. 本阶段不包含

- 不调用付费真实模型；真实教学质量、时延、费用仍沿用项目状态中的待验结论。
- 不代替产品经理完成手机 Chrome / Safari 的真实麦克风和讯飞词级验证。
- 不新增场景、指标或长期记忆能力。

## 5. 接口契约补齐

- `GET/POST /api/v1/phrase-cards` 响应补回已有数据模型字段 `source_session_id`。
- 语块卡「练这一句」继续调用 `POST /api/v1/sessions/practice-sentence`。
- 语块卡「加入待复练」继续调用 `POST /api/v1/review-queue`，依赖现有同源幂等约束。
- 错误仍沿用 `{ "error": { "code", "message" } }`。

## 6. 验收标准

- 390 / 768 / 1280 / 1440px 无意外横向溢出，手机导航文字不竖排、不截断，八个入口都可触达。
- 今日复练和语块卡具有与首页、待复练、进步中心一致的页面层级；加载、空、错误和完成状态可辨认。
- 语块卡可进入单句练习，也可幂等加入原待复练队列。
- 后端 Mock、前端 typecheck、lint、build 全部通过。
- 保存桌面与手机截图、验收步骤和阶段闸门表。

## 7. 风险与回退

- 风险：手机导航入口较多。处理为横向滚动并自动把当前项带入可视区，不隐藏任何功能。
- 风险：语块卡旧接口未返回来源会话标识。采用向后兼容的新增响应字段，既有消费者不受影响。
- 回退：改动集中在页面组件、样式和一个兼容字段，可按文件回退，不涉及数据迁移。

- 后端 Mock 110/110 通过；前端 typecheck、Lint、生产构建通过。
