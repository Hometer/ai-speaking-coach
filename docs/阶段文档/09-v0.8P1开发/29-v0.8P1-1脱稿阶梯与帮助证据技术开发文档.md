## 1. 范围与不做

### 1.1 本子阶段做

1. 在现有「练这一句」单句跟读之上，升级为**五段脱稿阶梯**：
   `看全文 → 补关键词 → 看结构 → 脱稿说 → 换题用`。
2. 用**已实际展示的帮助层级**作为完成判断证据（帮助证据）：
   - 看全文 / 补关键词 → 有参考练习（reference）
   - 看结构 → 提示下完成（hinted）
   - 脱稿说 → 独立表达（independent）
   - 换题用 → 迁移证据（transfer）
3. 结果**写回原待复练项**（沿用 REQ-23 跨日规则，不创建重复弱项）。
4. 阶梯状态、帮助记录、完成证据持久化，重启可恢复。

### 1.2 本子阶段不做（放到后续 P1 子阶段）

- REQ-29 今日复练组合（另做）。
- REQ-30 示范与本人录音对比（另做；本阶段仅保留「听示范」入口，不做并列对比/重录互斥）。
- REQ-31 语块卡（另做；本阶段仅用来源原句 + 建议句 + 中文意图 + 一个主要语块）。

## 2. 现状与差距

- 现状：`create_sentence_practice` 只创建一条 `sentence_practice` 会话，页面提供「听示范 + 录音跟读 + 跳过」，`submit_practice` 用讯飞短句评测给总分。
- 差距：没有「逐级减少帮助」的阶梯；没有「帮助证据 → 完成结论」的映射；没有「换题迁移」；没有把结果写回待复练项。

## 3. 数据模型

新增 `DrillAttempt`（脱稿尝试），沿用现有 `Session` / `Turn` / `ReviewQueueItem`。

```text
DrillAttempt
  id                自增主键
  user_id           归属用户
  source_session_id 来源会话（改进建议所属会话）
  source_turn_id    来源回合（改进建议）
  drill_session_id  本次脱稿会话 id
  stage             当前/本次尝试阶段：full_text | fill_blanks | structure | free_speak | transfer
  visible_help      实际展示的帮助内容（阶段对应：完整句/挖空句/结构提示/中文意图/迁移题；脱敏，不存用户原句）
  answer_text       用户本次回答（text/转写）
  result            本次结果：reference | hinted | independent | transfer | pending | failed
  ended_reason      completed | skipped | user_ended | error
  created_at / ended_at
```

`Session` 增加字段（迁移幂等，沿用 `migrate_db`）：

```text
drill_stage       当前阶段（full_text/fill_blanks/structure/free_speak/transfer/ended）
drill_target      本次脱稿目标句（建议句）
drill_meaning     中文意图
drill_chunk       目标语块（主要语块，用于补关键词/看结构）
```

## 4. 后端设计

### 4.1 进入阶梯（练这一句）

`POST /sessions/practice-sentence`（现有）扩展：
- 来源必须是有效改进建议（未被争议 / 来源未失效 / 有可练句）——已校验。
- 创建 `Session(practice_type="drill", drill_stage="full_text", ...)`，开场展示来源原句 + 建议句 + 中文意图 + 目标语块，并合成建议句示范音频（TTS 失败不阻断，audio_status 降级）。

### 4.2 阶段状态机（确定性，后端持有）

| 当前阶段 | 用户看到 | 提交后判定 |
| --- | --- | --- |
| full_text 看全文 | 完整英文 + 中文意思 + 示范 | 成功→fill_blanks；失败→可重试/降级/跳过 |
| fill_blanks 补关键词 | 句中去掉 1~3 个关键语块留空 | 成功→structure；失败→降级到 full_text |
| structure 看结构 | 只显示关键词/句首/结构提示 | 成功→free_speak；失败→降级到 fill_blanks |
| free_speak 脱稿说 | 只显示中文意图 | 成功→transfer；失败→降级到 structure |
| transfer 换题用 | 显示相似新问题，不显示建议句 | 成功→完成（迁移证据） |

- 后端持有当前 `drill_stage`，**不信任前端传来的阶段**（与 organize 层级同理）。
- 支持：跳级（一次成功直接向下一阶段，用户在 transfer 前可主动「跳过当前级」）、降级（判定失败时回退一级）、跳过（跳过整个阶梯）、结束。
- 判定以**语义完成 + 可理解性**为主：合理同义表达不因未逐字复现而失败；固定文本匹配只作辅助，不能单独决定独立完成。

### 4.3 帮助证据 → 完成结论

- full_text / fill_blanks 阶段提交成功 → `reference`（有参考练习）。
- structure 阶段提交成功 → `hinted`（提示下完成）。
- free_speak 阶段提交成功 → `independent`（本次表达独立证据）。
- transfer 阶段提交成功 → `transfer`（迁移证据）。
- 失败/跳过/退出 → 不升级，保留当前阶段与原结论。

### 4.4 写回待复练项

脱稿或换题成功后，写回 `ReviewQueueItem`：
- `independent`：成功次数 +1（本次独立表达），到期时间 +24h。
- `transfer`：成功次数 +1（迁移证据），到期时间 +24h。
- 两次独立成功且间隔 ≥24h 才「掌握」——沿用 REQ-23 / AC07-08 的确定性服务端校验，不信任前端。
- 同一来源只保留一条有效队列记录；写回不创建新弱项。

### 4.5 换题（transfer 题目）

- 优先使用**已审核替代题**：从场景 `variations` + `reference_expressions` 派生相似新问法（确定性）。
- 生成失败用备用题；仍失败则保留 `pending`，不伪造迁移证据。
- 迁移题改变问题表述或条件，只有真实新回答生成迁移证据。

## 5. 前端设计

- 练这一句页面改为「阶梯卡」：顶部显示当前阶段名 + 帮助内容 + 中文意图/目标语块；底部「听示范 / 录音 / 文字提交 / 降级 / 跳过 / 结束」。
- 阶段由后端 `drill_stage` 驱动，刷新从 `get_session` 恢复，不靠前端 state。
- 换题阶段只显示新问题，不显示建议句。
- 结果展示「有参考练习 / 提示下完成 / 独立表达 / 迁移」对应文案，与回顾、待复练口径一致。

## 6. 验收标准（AC08-01 ~ AC08-05）

| 用例 | 可观察通过条件 |
| --- | --- |
| AC08-01 | 完整文本、补关键词、结构提示、中文意图、换题五个阶段按规则进入 |
| AC08-02 | 用户可跳级、降级、跳过、退出，状态与帮助记录正确、重启可恢复 |
| AC08-03 | 看全文/补关键词/看结构提交不得显示独立完成（分别 reference / reference / hinted） |
| AC08-04 | 合理同义表达按原意判定成功，不要求逐字复现 |
| AC08-05 | 换题改变问题表述或条件，只有真实新回答生成迁移证据；迁移证据写回待复练项 |
