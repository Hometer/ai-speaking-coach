## 2. 七日训练计划（REQ-25）

### 2.1 产品行为

- 用户选目标：求职准备 / 职场表达 / 旅行准备 / 日常开口。
- 生成 7 天计划，每天 = 一个主场景 + 一个可选复练（从待复练队列取到期项）。
- 允许暂停、跳过、重新开始；没有完成不显示惩罚性语言；调整依据可见。
- 无足够历史时用审核过的默认计划；模型不能自行生成未经审核的考试标准/职业结论/难度等级。

### 2.2 生成规则（确定性，不调模型）

- 目标 → 场景系列映射：
  - 求职准备 / 职场表达 → 职场与求职（career）
  - 旅行准备 → 旅行与生活（travel）
  - 日常开口 → 日常交流（daily，可组合低难度生活场景）
- 7 天从目标系列取场景循环排布，每天一个主场景；可选复练 = 队列到期项（无则空）。
- 调整依据：MVP 阶段默认计划为主；有历史时若某场景近期多次用「中文转英文」帮助，则在计划里标注「建议先做相近的信息确认练习」，不改变场景本身。

### 2.3 数据与接口

| 项 | 设计 |
| --- | --- |
| 实体 | `TrainingPlan`：user_id、goal_type、days_json（7 天计划+状态）、status、created_at、updated_at |
| 接口 | `POST /api/v1/training-plan`（创建/生成，body=goal_type）；`GET /api/v1/training-plan`（当前计划）；`POST /api/v1/training-plan/{day}/skip`；`POST /api/v1/training-plan/restart` |
| 约束 | 每天最多一个主任务 + 一个可选复练；只组合已审核场景 |

## 3. 最小质检工作台（REQ-27）

### 3.1 产品行为

- 内部页面，不面向普通用户（不出现在普通导航）。
- 审核员按版本 / 场景系列 / 场景 / 输入类型 / 帮助类型 / 评价结果 / 错误码筛选脱敏会话。
- 展示问题、用户文本、教练回复、评价证据、费用、时延、争议状态；默认不播放录音。
- 标记：误纠错、错误完成、追问无关、帮助越级、证据不足、不当内容；标记可追溯到版本。

### 3.2 权限与安全（底线）

- **质检员独立身份**：`config` 增加 `qa_invite_codes`（逗号分隔质检邀请码，默认空=无质检员）；新增 `get_qa_user_id` 依赖，后端校验，前端隐藏入口不算权限控制。
- 普通用户访问质检接口一律 403；质检页不在普通导航出现。
- 默认脱敏文本；只有取得单独授权的质检片段才可播放；不采集/回显密钥。

### 3.3 数据与接口

| 项 | 设计 |
| --- | --- |
| 实体 | `QualityLabel`：id、session_id、turn_id、issue_type、conclusion、reviewer_id、review_version、created_at |
| 接口 | `GET /api/v1/qa/sessions`（筛选脱敏会话）；`POST /api/v1/qa/labels`（标记）；`GET /api/v1/qa/stats`（版本统计） |
| 前端 | 内部页 `/qa`，质检员身份可访问，展示筛选列表 + 标记表单 |
