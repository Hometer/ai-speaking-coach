> 依据：PRD v0.7（6.6 / 6.8 / 6.9 / 9.1 / 9.2 / 11）、现有代码、通用技术栈手册。
> 状态：技术方案稿，待产品经理确认后进入编码。本阶段只出文档，不写代码。

## 1. 范围

P1 首批三项（与 v0.6 延续性最强、可复用现有回顾/记忆/评测数据）：

1. 待复练队列（REQ-23）
2. 进步中心（REQ-24）
3. 发音证据（REQ-22）：有证据的词级反馈 + 争议传播 + 证据边界

**暂缓**：七日训练计划（REQ-25）、最小质检工作台（REQ-27）留 P1 后续批次，避免一次铺开。

## 2. 现状盘点

| 能力 | 现状 | P1 目标 |
| --- | --- | --- |
| 单句复练 | 已有「练这一句」创建一次性 sentence_practice 会话，跨会话不延续 | 升级为跨日待复练队列（到期/复测/掌握） |
| 历史统计 | 只展示次数、轮次、完成状态 | 进步中心：完成数、独立完成率、帮助使用率、到期复练完成率、已掌握数、语音可评估率 |
| 发音反馈 | 前端只显示一个总分；mock 评测 `notes` 写死 `experience`（面试残留） | 三层反馈 + 词级证据边界 + 争议传播；mock 只总分、不推测词级 |

## 3. 数据变化

新增两张表（沿用 SQLite + `Base.metadata.create_all` + 幂等迁移）：

| 实体 | 关键字段 |
| --- | --- |
| `ReviewQueueItem` | user_id、source_session_id、source_turn_id、target_ability、suggestion_sentence、evidence_status、status（pending / practicing / awaiting_retest / mastered / disputed / invalid）、created_at、due_at、last_practiced_at、retest_result |
| `ProgressSnapshot` | user_id、window（如 7d）、metrics_json、calc_version、created_at |

派生数据保留来源标识与计算版本；源文本修订/删除后队列项与进步指标可定位并失效（沿用 v0.6 数据边界）。

## 4. 接口变化

| 接口 | 说明 |
| --- | --- |
| `POST /api/v1/review-queue` | 用户确认后把回顾建议加入队列（body：source_session_id、source_turn_id） |
| `GET /api/v1/review-queue` | 队列列表（含状态、到期、复测结果） |
| `POST /api/v1/review-queue/{id}/retest` | 到期复测提交（新问题、无完整参考，独立成功才推进） |
| `PATCH /api/v1/review-queue/{id}` | 跳过 / 延后 / 删除 / 标记争议 |
| `GET /api/v1/progress` | 进步中心事实型指标（后端计算，前端不自行拼接权威结论） |
| 发音反馈 | 扩展现有跟读评测返回：`total_score`（整句）+ `word_items`（有真实证据时最多三处，mock 恒为空） |

统一错误结构、幂等键（创建队列项/提交复测）、SSE 以 done/error 收尾、进步指标后端计算等原则继续沿用。

## 5. 关键实现约定

1. **待复练队列**：回顾建议经用户确认才入库；跟读完成 → `awaiting_retest`；复测换问题、无完整参考，一次独立成功=阶段完成，两次间隔 ≥24h 的独立成功=已掌握；首页只推荐一项到期项。
2. **进步中心**：只展示事实型指标（完成数、独立完成率、帮助使用率、到期复练完成率、已掌握数、语音可评估率），不绘制伪精确四维分数；进步统计与学习记忆分开，关闭记忆仍可查看。
3. **发音证据**：mock 模式只返回整句总分，`word_items` 恒为空（零容忍无证据词级结论）；real 模式仅在讯飞返回原始词级证据时展示最多三处；争议项不进队列/记忆。
4. **去面试残留**：mock 评测 `notes` 不再写死 `experience`，改为基于参考句的确定性占位或直接空。

## 6. 验收用例

- 回顾建议经用户确认进入队列，来源会话/回合/目标能力/到期时间可追溯（AC07-06）。
- 跟读后进入待复测；新问题无完整参考；复述参考不能标为独立完成（AC07-07）。
- 两次间隔 ≥24h 的独立成功才标记已掌握（AC07-08）。
- 删除源练习后，进步指标重算，关联队列项和证据不可访问（AC07-09）。
- 记忆关闭时仍可查看进步中心，进步数据不注入教练上下文（AC07-10）。
- mock 下发音反馈只有整句总分，无词级结论；有原始词级证据时最多展示三处（AC07-04）。
- 用户标记发音反馈有误后，该项不进入记忆和队列（AC07-05）。
