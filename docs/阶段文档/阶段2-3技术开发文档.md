# 阶段 2.3 技术开发文档｜练习回顾 + 历史/删除 + 学习记忆 + 录音清理

> 配套文档：《AI口语练习PRD-v0.1.md》（v0.4）、通用技术栈手册、阶段 2.1/2.2 文档。
> 本文档只覆盖阶段 2.3。正式前端（阶段 3）不在本阶段实现。

## 一、阶段目标

- 交付范围：结束会话时生成**练习回顾报告**；**历史列表/详情/删除**；**学习记忆**（默认关闭，可开关/查看/清空，随源练习删除传播）；**录音清理**；完善故障降级（保存失败可重试）。
- 阶段产物：
  1. 练习回顾：目标完成情况+证据、表现较好片段、最多 3 条改进建议（用户原句/建议/中文解释/替换练习句/关联回合）、完成度评价、下次练习建议、输入方式统计；证据不足标注"待验证/无法判断"。
  2. 历史：`GET /sessions`（列表）、`GET /sessions/{id}`（详情含回顾）、`DELETE /sessions/{id}`（级联删除回合/评估/派生记忆）。
  3. 学习记忆：默认关闭；`POST /users/me/memory` 开关；`GET/DELETE /users/me/memories` 查看/清空；关闭后停止读写；删除源练习时删除派生记忆。
  4. 录音清理：会话结束后清理 `data/uploads` 中过期录音（目标 10 分钟）。
  5. 回顾生成：mock 确定性聚合 + 真实 LLM 结构化骨架（待验）。
- 验收标准：mock 测试全部通过；最小界面可走通"结束→看回顾→历史查看/删除→记忆开关"。真实模型冒烟待验（无 Key）。
- 明确不做：正式前端视觉（3）、真实模型/讯飞接入（有 Key 后冒烟）、记忆的"≥2 独立证据"精确规则（阈值校准属 PRD 11.2，本阶段简化为候选观察，规则标注待校准）。
- 主链路片段：**结束会话 → 生成回顾 → 历史查看/删除 → 记忆候选生成/开关**。

## 二、技术适配摘要

- 开发路径：纵向切片（延续）。
- 采用默认方案：沿用 SQLAlchemy + SQLite；新增表 `memories`、`Session.review`（JSON 文本）、`User.memory_enabled`。
- 偏离/暂缓：真实 LLM 回顾生成、讯飞评测、时延/成本实测均待验（无 Key）；录音清理用"会话结束触发扫描"实现，正式定时任务在部署阶段接入。

## 三、技术栈与模型

- 组件：沿用 2.2；新增 JSON 序列化回顾、文件清理。
- 模型：回顾生成候选通义千问（结构化输出，待验）；mock 阶段用确定性聚合 + 模板建议。

## 四、环境与配置

- 新增配置：`UPLOAD_RETENTION_MINUTES`（默认 10，录音清理时限）。
- 需要产品经理提供：无（本阶段 mock 推进）。

## 六、数据、资产与状态

- 新增 `Memory` 表：id、user_id、text、source_session_id、created_at。
- `Session.review`：JSON 字符串（回顾报告）；`User.memory_enabled`：布尔（默认 False）。
- 状态机不变；结束会话时生成回顾并落库（幂等，已结束则返回已有回顾）。
- 资产清理：`data/uploads` 中超过 `UPLOAD_RETENTION_MINUTES` 的录音文件在会话结束时扫描删除；合成音频 `data/audio` 本阶段保留（2.3 后接入统一清理）。

## 七、API / 工具设计

统一错误结构不变。身份仍由 `X-User-Id` 注入。

| 接口 | 方法/路径 | 说明 |
| --- | --- | --- |
| 会话列表 | GET `/api/v1/sessions` | 当前用户的历史会话（含状态、时长、回顾摘要） |
| 会话详情 | GET `/api/v1/sessions/{id}` | 含回顾（`review` 字段） |
| 删除会话 | DELETE `/api/v1/sessions/{id}` | 级联删除回合/评估/派生记忆 |
| 结束会话 | POST `/api/v1/sessions/{id}/end` | 生成回顾后返回摘要+回顾 |
| 记忆开关 | POST `/api/v1/users/me/memory` | `{enabled}` |
| 记忆列表 | GET `/api/v1/users/me/memories` | 当前用户候选记忆 |
| 删除单条记忆 | DELETE `/api/v1/users/me/memories/{id}` | |
| 清空记忆 | DELETE `/api/v1/users/me/memories` | |

回顾结构（`review` 字段，JSON）：`{goal_status, evidence, good_fragments, improvements[], ratings{}, next_suggestion, end_reason, input_breakdown{}}`。改进建议每条含 `original/suggestion/explanation_cn/practice_sentence/turn_id`。

## 八、Prompt 设计

- 回顾生成（真实版，待验）：输入会话结构（目标、各回合文本与评估、提示/跟读/文字统计、结束原因），输出结构化回顾（≤3 条改进建议，每条关联回合，证据不足标"无法判断"）。mock 阶段用确定性聚合，不调用模型。

## 九、验收界面或纵向切片

扩展 `index.html`：结束页展示完整回顾（改进建议列表）；新增"历史"区（列表/查看/删除）；新增"记忆"区（开关/列表/清空）。仍为临时验收工具。

## 十、测试要求（mock，离线必跑）

1. 结束会话生成回顾：含 goal_status、evidence、improvements（≤3 条）、ratings、input_breakdown；已结束再次 end 幂等返回已有回顾。
2. 历史：列表只返回当前用户；删除后详情 404，且级联删除回合/评估/派生记忆。
3. 记忆：默认关闭时列表为空/不生成；开启后结束会话生成候选记忆；清空/单删生效；关闭后不生成；删除源会话时派生记忆删除。
4. 录音清理：过期录音被删、未过期保留。
5. 转写/评价有误反馈（如实现）：错误结论在复核前不进记忆。

## 十一、验收清单（产品经理照着点）

1. 完成一段练习（按 2.2 流程），点「结束练习」，看到回顾报告（目标结果、改进建议、下次建议）。
2. 打开「历史」，看到刚才的练习记录；点进详情能看到对话和回顾；点「删除」后记录消失。
3. 打开「记忆」（默认关闭），开启后结束一次练习会生成候选记忆；可查看、清空。

## 十二、风险与待确认项

- 无 Key：回顾生成的措辞为模板、评测为 mock，真实质量待冒烟；如实标"待验"。
- 记忆"≥2 独立证据"精确规则与阈值校准（PRD 11.2）本阶段简化为"候选观察"，标注待校准。
- 必须由产品经理决定的问题：无。
