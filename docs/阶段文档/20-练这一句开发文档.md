# 「练这一句」开发文档（v0.6 · REQ-04/08/10）

> 依据：PRD v0.6 第 6.11 节。本阶段只做反馈卡"练这一句"，数据边界（逐条确认）随本功能一并落实。

## 一、阶段目标

让有效反馈卡上的改进建议可"练这一句"：会话内短练，或结束后创建一次性单句复练记录（不开启记忆、不复制旧录音、不计入面试完成/北极星）。

## 二、数据模型变更

- `Session` 增加 `practice_type`（String，默认 "interview"；"sentence_practice" 表示单句复练）、`source_session_id`、`source_turn_id`、`practice_sentence`、`practice_goal`。

## 三、后端方案

### 创建单句复练

- 新增 `POST /sessions/practice-sentence`，请求 `{source_session_id, turn_id}`。
- 校验：源会话属于当前用户、已结束、改进建议存在且未争议/未失效；无效则拒绝（不生成通用句子冒充）。
- 创建新会话：`practice_type="sentence_practice"`，目标为"完成这句表达的尝试并查看反馈"，开场即展示建议句 + 示范（TTS），状态直接进入 `PRACTICE`；记录来源会话/建议/版本。
- 记忆关闭时仅带入本次确认的句子与目标，不注入旧回顾/弱项；重复点击/重试只创建一个有效记录（按来源 turn_id 幂等）。

### 单句复练流程

- 用户录音/文字尝试该句 → `submit_practice` 评测 → 反馈；可重试、跳过、结束。
- 结束统一收尾（复用 finalize），回顾不强制三条建议。
- 统计：`practice_type="sentence_practice"` 的会话不计入普通面试完成率、北极星有效复练分子。

### 来源与数据

- 旧录音不复制；新会话只生成必要示范与保存本次录音，按原期限清理。
- 源建议争议/删除后，新记录标来源失效；删除源会话时级联清理复制文本与派生引用。

## 四、前端方案

- 回顾/历史详情的改进建议卡增加「练这一句」按钮（与「有误」并列）。
- 已结束会话：点击后弹确认（展示将带入的具体句子、改进目标、"一次性使用、不开启记忆"说明），确认后调创建接口并跳转练习页。
- 会话内：复用当前跟读分支（把该句设为 practiceSentence），直接短练。

## 五、测试要求

1. 创建单句复练：源会话/建议校验、来源记录、幂等（重复创建只一条）。
2. 单句复练不计入面试完成/北极星（按 practice_type 区分）。
3. 源建议争议/删除后，新记录来源失效。
4. 记忆关闭时不注入旧回顾/弱项。

## 六、验收清单

1. 有效反馈卡可"练这一句"，结束后确认后进入一次性单句练习。
2. 会话内可直接短练该句。
3. 单句练习单独统计，不混入面试完成与北极星。

## 七、风险与回退

- 单句复练为简化实现（开场即 PRACTICE），迁移检验、慢速播放等真实细化待内测验证。
