# AI 口语教练｜情景对话与学习评估

独立产品设计与推进｜AI 产品经理

成人英语口语练习｜2026.09—至今

**项目背景**

面向成人英语学习者，围绕职业与面试、旅行与生活、日常沟通设计情景练习。针对提示依赖、辅助作答与独立掌握容易混淆，以及练习后缺少持续复习的问题，构建情景对话、分层帮助、独立评估与复习计划相衔接的学习流程，帮助学习者逐步过渡到独立表达。

**核心职责**

- **AI 口语产品规划与场景设计** 负责目标场景、练习任务、产品范围及验收设计，规划 3 个系列、7 个场景，明确各场景的表达目标与任务要求；以邀请试用方式推进产品验证，优先交付练习、反馈和复习的完整流程。
- **AI 教练决策与独立评估设计** 串联情景练习、教练追问、提示帮助、跟读和练习复盘，区分教学辅导与学习效果判断；教练负责推动表达与提供帮助，评估环节结合回答内容及帮助记录判断完成情况，避免将对话顺利结束直接视为掌握。
- **分层提示与独立表达评估** 设计 4 类帮助及“完整示范、填空、结构提示、独立回答、迁移表达” 5 级练习阶梯，记录帮助使用情况；将辅助完成与独立完成分开判断，并通过迁移表达检查学习者能否在变化后的情境中运用所学内容。
- **学习反馈与间隔复习循环** 将练习反馈用于短语卡整理、间隔复习和 7 日练习计划，整合今日练习与进度展示，使单次练习能够进入后续复习，支持学习者重新练习薄弱表达并查看完成情况。
- **语音模型接入与 AI Coding 实现** 使用 FastAPI／SQLite、Next.js／TypeScript 推进原型实现，支持文字与语音输入、跟读回放及练习质检；设计 Qwen 对话、Paraformer 识别、CosyVoice 合成与讯飞英文评测的接口方案，分别明确对话、识别、合成和评测的职责与验证要求。
- **大模型教学评测与标准修订** 基于 35 条构造回答，检查实际模型的教学反馈、回答完成情况及独立掌握判断是否与帮助使用记录一致；定位辅助作答被误判为独立完成的问题，收紧评估标准，并将相关案例纳入后续回归检查。

**项目成果**

- 构建覆盖 3 个系列、7 个场景的口语练习体系，交付情景练习、提示帮助、跟读、复盘及复习计划功能，形成从练习到反馈、再到复习的完整产品流程。
- 建立 4 类帮助与 5 级练习阶梯，将帮助使用记录纳入评估依据，明确辅助完成、独立回答与迁移表达之间的判断边界。
- 调用实际模型检查 35 条构造回答对应的教学反馈与评估结果，识别独立完成误判并修订评估标准，形成可复用的质检样例。
- 当前处于邀请试用与产品验证阶段，持续验证学习流程、反馈有效性和复习体验；真实学习效果与用户留存尚待验证。
