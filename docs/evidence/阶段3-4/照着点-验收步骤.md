# 阶段 3-4 验收步骤（照着点）

> 前端：<http://localhost:3000/>，后端已在 8000 运行。

## 照着点

1. **历史页**：打开 `http://localhost:3000/history`，看到练习列表（时间 + 结果 + 轮数）；点「查看」展开对话和回顾；点「删除」该条消失。
2. **记忆页**：打开 `http://localhost:3000/memory`，默认「开启记忆」未勾选；勾选后，回首页练一次并「结束练习」，再回记忆页看到候选记忆；可「删除」单条或「清空全部」。
3. **录音计时**：首页点「开始练习」→ 点「🎤 录音回答」，按钮旁显示「已录 X 秒」；录到 50 秒变红提示「还剩 10 秒」；到 60 秒自动停止提交；点「取消」则丢弃不提交。
4. **回顾**：对话页点「结束练习」，下方展示「练习回顾」（改进建议 / 下次建议）。

## 说明

后端目前是 mock 模式（AI 回复固定、语音静音）；语音识别与讯飞跟读打分已单独真实实测通过，后端切真实模式后前端无需改动。
