# 照着点 · 验收步骤（v0.7 P1 补充：七日计划 / 质检工作台）

## 打开地址

- 前端：http://localhost:3000（邀请码 `test-a`；质检员用 `qa-a`）

## 验证七日计划

1. 登录后，左侧导航点「七日计划」。
2. 选一个目标（求职准备 / 职场表达 / 旅行准备 / 日常开口），点「生成 / 更新计划」。
3. 应看到 7 天安排，每天一个主场景（旅行目标→酒店入住/餐厅点餐交替；求职→面试/新同事/会议）。
4. 点某天的「跳过」，该天变「已跳过」；点「重新开始」恢复全部待练。
5. 每天最多一个主场景 + 一个可选复练（有到期队列项时挂到第一天）。

## 验证最小质检工作台（权限）

6. 普通用户（`test-a`）打开 http://localhost:3000/qa ，应看到「无质检权限」错误提示。
7. 切换邀请码为 `qa-a`（退出后重新登录），打开 /qa，应正常进入「质检工作台」，看到版本统计和脱敏会话列表。
8. 对某条用户回答选问题类型（误纠错/错误完成/追问无关/帮助越级/证据不足/不当内容）点「标记」，顶部统计数增加。

## 验证默认不播放录音

9. 质检页会话列表只显示文本，不出现录音播放控件。
