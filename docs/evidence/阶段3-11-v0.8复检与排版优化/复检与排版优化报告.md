## 二、发现的问题与修复

### F-01（已修复）计划页报 "HTTP 200"
- 现象：`/plan` 无计划时顶部出现错误横幅 "HTTP 200"。
- 根因：`frontend/lib/api.ts` 的 `handle()` 把 `200 + JSON null` 当作错误（`data === null` 误判），`getPlan()` 无计划返回 `null` 时被抛成 "HTTP 200"。
- 修复：`handle()` 只在 `!res.ok` 时抛错，合法 `null` 响应按成功返回。

### F-02（已修复）脱稿结束提示编造"已写回待复练"
- 现象：脱稿阶梯点"结束/跳过"后，页面固定提示"本次表达已写回待复练记录"，但实际未写回。
- 修复：`drill_view` 新增 `outcome`（transfer / independent / ended），前端按真实结论提示，不再编造写回。

### F-03（已修复）语块卡"可替换部分"语法错误
- 现象：`可替换部分` 用整句关键词替换，生成 "I have three years of project in software development."（语法错误，且不是"部分"）。
- 修复：改为展示主要语块与可替换同场景词（如 `experience（可换成 project / result）`）。

### F-04（已修复）练习回顾缺"加入待复练"
- 现象：练习页回顾只有"练这一句/语块卡/评价有误"，缺 PRD 6.9 要求的"加入待复练"。
- 修复：回顾每条建议补"加入待复练"入口。

## 三、本轮排版优化

1. **首页**：新增"今日任务区"，汇总「今日复练 / 七日计划 / 待复练」三张卡；保留唯一主操作"开始练习"。
2. **对话页**：暂停/结束固定到对话卡片头部（始终可见）；普通输入区与跟读/脱稿阶梯互斥显示，消除两套录音按钮并存；跟读进行时只保留"慢速示范 / 录音跟读 / 跳过"，脱稿时只保留阶梯操作。
3. **统一复盘**：结束后的"练习回顾"升级为"本次练习复盘"，整合小目标完成情况、示范与本人录音对比、表达建议（练这一句/语块卡/加入待复练/评价有误）、脱稿练习结果。
4. **导航**：桌面侧栏按「练习 / 今日与复练 / 练习材料 / 记录」四组收拢八个入口；移动端保持横向滚动，不删除任何入口。
5. **视觉**：沿用奶油白 + 森林绿，新增卡片/复盘/任务区样式与既有标题层级、按钮尺寸、空状态保持一致。
