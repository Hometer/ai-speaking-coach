## 3. 产品经理照着点

1. 在项目根目录启动后端：`cd backend && PROVIDER_MODE=mock ../.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`。
2. 新开终端启动前端：`cd frontend && npm run dev`。
3. 浏览器打开 `http://localhost:3000`，缩窄到手机宽度；顶部导航应保持横排，可左右滑动，当前入口自动可见。
4. 打开「今日复练」；应看到完整页面标题和到期摘要。开始后可看到进度、提示、提交、跳过、延后、内容有误和结束入口。
5. 打开「语块卡」；每张卡应有来源、建议、语块、解释、情境、替换、新例句，以及「练这一句」「加入待复练」。
6. 点击「加入待复练」后按钮显示「已加入待复练」，刷新后仍保持；点击「练这一句」进入脱稿阶梯页面。
7. 打开「进步中心」；桌面八项指标为两行四列，手机为两列，页面无横向溢出。
