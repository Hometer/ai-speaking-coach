# 阶段 2.1 验收步骤（照着点）

> 后端已在运行：<http://127.0.0.1:8000/>。如果打不开，告诉我，我给你重开。

## 照着点

1. 打开浏览器（Chrome 或 Safari），地址栏输入 `http://127.0.0.1:8000/`，回车。
2. 看到标题 **「AI 口语练习 · 最小验证页」**，下面有「录音」「文字输入」两块，算对。
3. 在「3) 文字输入」的输入框里打一句英文，例如：
   `I am a software engineer.`
   点「发送」。
4. 看到「AI 说」下面出现一句英文回复（当前 mock 模式是固定句），下面出现一条播放条，算对。
5. 点播放条：能播（当前 mock 是静音，听不到声音是**正常的**；真实模型才会出声）。
6. 点「开始录音」：浏览器会弹出"是否允许使用麦克风"，点「允许」，对着麦克风说一句英文自我介绍，再点「停止」。
7. 看到「你说的」下面出现一句转写（mock 是固定示例句）、「AI 说」出现回复，算对。

## 说明（为什么现在是 mock）

现在还没有填入阿里云百炼的 Key，所以：转写和回复是**固定示例**、AI 语音是**静音**。这是开发期的正常状态，用来验证"录音 → 转写 → 回复 → 播放"这条链路通了。

**等你要验收真实效果时**，把阿里云百炼 Key 给我（我会给你"照着申请、填到哪一行"的步骤，Key 只填进本地 `.env`，不要贴到对话里），我再帮你跑真实冒烟。
