## 教练提示词 A/B 第三轮（v5，2026-09-23，进行中：代码与 Mock 已就绪，真实模型待确认费用后运行）

> 范围：只做一轮窄范围修复「回复生硬」，不开发 v0.8 P1，不通过增加固定开场白模板解决。

### 根因（不是措辞问题）

1. **规则优先级冲突**：v4 把「回答用户直接提问」只写在 follow_up 规则里，且声明「apply to follow_up ONLY」。当模型选 hint / suggest_practice / recheck 时这条不生效；同时「必须选一个教学动作并追问用户」的高层要求与「绝不编造事实」互相挤压，模型没有角色事实可答，于是跳过用户问题、只问自己的追问。
2. **没有可用的教练角色事实**：新同事 / 新朋友等双向场景没有 coach_persona，模型既不能凭空编造、又没有被授权的事实，只能不答。
3. **示例材料进入决策上下文**：`submit_turn` 把 follow_ups / reference_expressions（含 Li、30%、Alex 等示例）整体塞给教练，模型把示例当事实/脚本（酒店「Is it under the name Li?」、面试「I led a project that improved delivery speed by thirty percent」）。
4. **多意图/子目标**：评估器不知道在评估哪个 subgoal（只传整目标 acceptable_points），且每回合只推进一个子目标——「认识新同事」一句「自我介绍 + 反问」只记了 self_intro，用户已提出的问题被漏掉。

### 修改点

| 文件 | 修改 |
| --- | --- |
| `app/services/prompts/coach.py` | 提示词 v4→v5：把「先回答用户直接提问」提升为对所有动作生效的第一优先规则；「回答用户问题不被继续追问覆盖」；整条最多两句、最多一个主要追问；新增 coach_persona 区块；新增「示例材料≠用户事实，禁止照抄」；评估提示词增加当前 subgoal |
| `app/services/prompts/scenarios.py` | 新同事/新朋友增加经审核的 coach_persona；新朋友 basic 开场去掉「I'm Alex」；新同事增加 co_complete 声明（反问可与自我介绍同句完成 ask_question） |
| `app/services/coach.py` | mock 教练的 follow_ups/reference_expressions 改从 SCENARIOS 按 scene_id 取（不再依赖上下文）；真实教练把 coach_persona 注入系统提示词 |
| `app/services/session_svc.py` | 教练决策上下文移除 follow_ups/reference_expressions（不再把示例材料交给模型），改传 coach_persona；评估上下文传 subgoal；实现 co_complete 多子目标推进（仅场景显式声明时，不影响新朋友两轮规则） |
| `backend/tests/test_scenarios.py` | 新增 2 条：新同事「自我介绍+反问同句」一轮完成；新同事「只自我介绍」不结束（反问子目标仍待完成） |

**失败率**：2/50（4%），均为 TTS websocket 建连超时（5s 未建立）；当前代码 TTS 失败直接报 `TTS_ERROR`，无重试/降级。

**费用（参考单价，以百炼控制台为准）**：
- LLM：58,633 in / 2,979 out tokens → 约 ¥0.053（可忽略）
- TTS：3,224 字符 → 约 ¥6.45
- 单回合约 **¥0.13**（TTS 占 99%）

### 关键结论（诚实记录）

1. **时延大头是 TTS（2.5s）+ 教练 LLM（1.3s）**；文字回合从请求到回复文本 P50 约 4.5s。
2. **未达 PRD 11.2「普通语音回合首个有效回复 P50 ≤2.5s」**，但需说明：本测为文字回合（不含 ASR），且当前 `text_turn_stream` 要等 TTS 合成完才下发 `chunk`（reply_text）——若改成「教练决策后先下发文本、音频异步补齐」，「首个有效回复」P50 可降到约 2s（评估 0.66s + 教练 1.33s）。语音回合再叠加真实 ASR（约 1~2s）。
3. **失败率 4% 集中在 TTS**，需要补 TTS 重试/降级（PRD 11.4 故障降级方向一致），否则真实内测会偶发「教练没声音、整回合报错」。
4. **单回合成本 ¥0.13 且 TTS 占 99%**，缓存/复用 TTS 或调低音色档可显著降本；当前 PRD 11.3「标准 5 分钟练习 ≤¥1」在 5 分钟约 8~10 回合时勉强贴近 ¥1（约 ¥1.0~1.3），需要实测更长会话确认。

以上时延/失败率/费用为 P0 第 5 项的首批数据；PRD 13.1 要求的「至少 200 个普通回合」大样本仍待扩量（可后续脚本再跑，或纳入真实内测一并采）。
