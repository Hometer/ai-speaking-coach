# 阶段 2.3 验收步骤（照着点）

> 后端已在运行：<http://127.0.0.1:8000/>。打不开就告诉我，我给你重开。

## 照着点

1. 浏览器打开 `http://127.0.0.1:8000/`，看到「AI 口语练习 · 最小验证页」和顶部三个按钮（开始练习 / 历史 / 记忆）。
2. 点「开始会话」，在输入框打一句短回答 `just working` 点「发送」（会进入跟读面板，这是 mock 规则，属预期）。
3. 点「结束练习」，看到「练习摘要与回顾」：目标完成情况 + 「改进建议」（原句 / 建议 / 说明 / 练习句）+ 评价 + 下次建议，算对。
4. 点顶部「历史」，看到刚才这条练习记录（时间 + 目标结果 + 轮数）。
5. 点记录的「查看」，能看到当时的对话和回顾；点「删除」，记录消失。
6. 点顶部「记忆」，看到「（暂无记忆）」；勾选「开启记忆」。
7. 回「开始练习」再练一次并「结束练习」，再回「记忆」，看到一条候选记忆（如「表达可以更完整…」）；点「清空」后消失。

## 说明（为什么现在是 mock）

现在没有真实 Key：教练回复是固定规则、评测是固定分数、语音是静音、回顾的改进建议措辞是模板。这一步验证的是**「回顾 / 历史 / 删除 / 记忆」这套数据与流程**是否跑通，不是 AI 说得好不好。

真实效果（教练看懂回答、真实评测、真实语音、真实回顾）在提供阿里云百炼 / 讯飞 Key 后补跑冒烟，闸门表里已如实标「待验」。
