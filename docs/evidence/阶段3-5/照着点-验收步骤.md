# 新版前端：照着点验收

日期：2026-09-21。本次为视觉与界面交互验证，服务使用 Mock；示例对话不代表真实模型教学能力。

1. 打开 **http://localhost:3000/**。看到奶油白背景、深绿场景卡、左侧导航，说明进入新版。手机宽度下导航移到顶部。
2. 如果看到凭证框，输入分配给你的邀请凭证并点“进入练习空间”；无效凭证应留在登录页显示错误。
3. 在首页分别点水平、难度和时长。被选中的选项有浅绿底与边框；开场示例随水平变化。展开“不知道从哪儿说起？”可看到准备提示。
4. 点“开始练习”。应显示教练开场、当前目标与输入区，不自动开启麦克风。
5. 点“暂停练习”，输入区应禁用；点“继续练习”恢复。在文字框填一段英文并点“发送”，能看到自己的回答和教练回复。
6. 点“需要帮助”，看到没听清、没听懂、不知道怎么组织、中文转英文四个入口。跟读卡保留录音与跳过操作。真实录音与服务商效果另行验收。
7. 点“结束练习”。应显示结束状态、回顾，不能再提交普通回答。刷新页面，双方对话与回顾仍在；“练这一句”先显示选定材料确认。
8. 点左侧“练习历史”，查看统计、真实记录和详情。删除单条/全部都会先确认；本次验收无需删除已有数据。
9. 点“学习记忆”，查看真实开关状态；切换后刷新应保持刚才的设置。检查完可恢复原设置。暂无记录时显示空状态，不显示虚构记忆。
