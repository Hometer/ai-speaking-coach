# P1 照着点 · 验收步骤

> 开发版地址：http://localhost:3000 （邀请码 `test-a`，浏览器已登录状态见截图；若提示缺少邀请凭证，在任意页面控制台执行 `localStorage.setItem("invite_code","test-a")` 后刷新）

## 一、脱稿阶梯（REQ-28）

1. 进入「练习历史」找一个已结束、有改进建议的会话（或先随便练一场）。
2. 回顾页某条建议点「练这一句」→ 进入脱稿阶梯页。
3. 按顺序看：**看全文**（完整英文+中文意思）→ 提交英文 → **补关键词** → 提交 → **看结构** → 提交 → **脱稿说**（只显示中文意图）→ 提交 → **换题用**（显示相似新问题）。
4. 每级提交后看提示文案：看全文/补关键词=有参考练习、看结构=提示下完成、脱稿说=独立表达、换题=迁移证据。
5. 试试「降一级」「跳过这级」「结束」，看状态是否正确、刷新后是否恢复当前层级。

## 二、今日复练（REQ-29）

1. 左侧导航点「今日复练」。
2. 有到期内容时显示「今天有 N 条到期内容 + 开始今日复练」；点开始。
3. 逐条：先回忆（空白）→ 可点「要提示」看原句 → 输入英文提交 → 完成/跳过/延后/标记有误。
4. 结束页显示完成数量、用提示数、跳过/延后数。
5. 验证：用了提示的条目回到 1 天间隔，独立完成的进下一档（1→3→7→14）。

## 三、示范与本人录音对比（REQ-30）

1. 进入脱稿阶梯/跟读页，听示范音频，点「慢速示范」切换 0.75x。
2. 录音跟读一次，提交后卡片下方出现「你的录音（本次评价使用）」。
3. 播放示范和本人录音，验证**互斥播放**（放一个自动暂停另一个）。
4. 评测失败时仍能听示范和自己的录音，页面说明没有发音评测。

## 四、语块卡（REQ-31）

1. 回顾页某条建议点「语块卡」→ 生成并跳转到「语块卡」页。
2. 查看字段：来源原句、建议表达、主要语块、中文解释、适用情境、可替换部分、新例句。
3. 点「练这一句」「加入待复练」入口验证可用。

## 五、进步中心新指标

1. 左侧导航「进步中心」。
2. 确认底部新增两张卡：**脱稿完成数**、**迁移成功数**（初始为 0，完成脱稿/换题后递增）。
