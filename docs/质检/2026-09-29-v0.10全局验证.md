## 按 PRD 核对出的阻断项

1. **AC10-01、REQ-01/23/28/29：文字被升级为口语独立证据。** 在隔离浏览器中只输入一条文字回答，结束页显示“小目标：独立完成”，进步中心显示“独立完成率 100%”，但“语音可评估率 0%”。`session_svc.submit_turn` 对 `input_type=text` 仍把评估器的 `independent` 写入子目标；`review.build_review` 和 `progress.get_progress` 未按输入模态隔离口语独立结论。应保留文字表达反馈，但不得把该记录计为语音独立或掌握证据；修复后补混合语音/文字回归。
2. **AC10-15：进步中心仅有 8 张总量卡片。** 后端 `progress.get_progress` 和前端 `/progress` 均未提供 PRD 要求的周趋势、前后七次对比、按场景查看、已掌握项目列表与样本数。现有独立率还受第 1 项污染，不能作为口语指标使用。
3. **AC10-18：七日计划尚未完整。** 当前生成接口只接收目标，`training_plan._generate_days` 不使用可用时间；前端没有暂停/恢复入口，已完成状态在页面上仍显示“待练”。服务端把“今天任意已结束的同场景会话”当作计划日完成，未核对计划第几天和有效回顾。
4. **AC10-19：质检工作台尚未完整。** `quality_label.list_sessions` 有部分筛选与脱敏，但返回项缺费用、时延、争议及证据版本；标签修改直接覆盖原行，只递增版本号，不能还原每次改动，达不到“所有标签变更有审计”的验收条件。现有测试只覆盖了版本号递增。
5. **AC10-16：事件实值在并发下需复核。** `generation_call` 使用模块级 `_last_usage` 保存最近一次模型用量，`session_svc` 随后读取。并发请求可能读到另一回合的 token 数。现有回归没有针对并发用量归属的测试。

## 尚不能作通过结论的范围

- P1 的识别风险流程和 P2 的计划/质检部分代码已存在，项目状态此前写“待开发”已不准确；但 AC09-01～11 与 AC10-18～19 尚无逐条完整验收证据。
- AC09-12 以及 PRD 15.5 的手机 Chrome/Safari、真实 ASR/讯飞词级、七场景教学抽样、200 回合费用/时延和四周内测，均待真实环境验证。本轮没有产生付费调用。
- 146/146 测试证明现有断言通过，不证明上面缺口已关闭；整版闸门保持未通过。

## 建议修复顺序

先修文字与语音学习证据隔离并补回归；再补进步中心的真实分母和明细视图；随后按 AC10-18/19 收口计划与质检，最后针对并发用量做故障注入。完成本地缺口后再安排 PRD 15.5 的真实验收。
