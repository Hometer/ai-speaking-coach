# PRD v0.10 代码复审

日期：2026-09-30。验收依据：`docs/PRD/AI口语练习PRD-v0.10.md` 第 6、9、10、11、12、14 节。本轮只审计和验证，不修改业务代码。检查在隔离 Mock 数据库与独立端口进行，没有调用收费模型或操作原有用户数据。

## 结论

**当前不能认定 PRD 功能均已开发或整版验收通过。** 后端 147/147 测试、前端 typecheck、lint、2/2 组件测试及生产构建均通过，但这些测试没有覆盖下列关键路径。P0-A/P0-B 中仍有本地可复现的缺陷，P2 的七日计划和质检台也尚未达到 AC10-18/19。真实语音、词级评测、教学效果、真机和费用仍单列待验。

## 本轮验证及边界

- 后端：`cd backend && ../.venv/bin/python -m pytest -q`，147/147 通过。
- 前端：`npm run typecheck`、`npm run lint`、`npm run test`（2/2）、`npm run build` 均通过。
- 隔离 Mock 数据复现了文字伪装语音、幂等重放、错误迁移、七日计划多天误完成及质检筛选；独立浏览器验证了计划场景链接错误。数据库和 8001/3100 测试服务已清理，未改原有 8000/3000 服务。
- 本轮未调用真实模型/ASR/讯飞，未测手机 Chrome/Safari、真实录音、200 回合时延与费用；这些保持“待验”。静态审计指出的缺口需修复后补针对性回归与真实验收。

## 修复顺序建议

先封住所有“文字伪造语音/错误迁移”写入成功证据的入口，并给创建、回合、阶梯、复练统一补请求键和同键同内容约束；随后修正计划按天关联、入口与展示，再完成 ASR 待确认状态恢复和语音操作；最后补齐进步口径、质检与历史筛选、预检及真实费用追溯。每项以对应 AC 用例复测，不以现有 147 条测试通过替代。
