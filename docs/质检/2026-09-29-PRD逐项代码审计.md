## 3. 最优先修的代码缺口

1. **学习证据不可靠。** 先修队列、今日复练和脱稿阶梯的题目/帮助/输入模态/来源绑定，禁止看着完整答案或输入无关文字获得口语独立、迁移、掌握。当前完成率、掌握数会被这些错误证据污染。
2. **核心请求缺幂等和处理中可退出。** 为开始练习、回答、今日复练尝试、跟读建立持久化的用户意图标识与唯一约束；处理中的暂停/结束应可用，并让刷新读取真实请求状态。
3. **回顾、发音、音频对比有明确验收遗漏。** 回顾最多两条且不推断语法达标；解析可靠的词级原始证据并允许争议；评测失败保留可回放录音和示范。
4. **指标与费用口径不能用于内测结论。** 用实际供应商用量、幂等计费与原子预算；按 PRD 定义事件和分母，重算进步中心与内测指标。

七日计划、质检工作台完整功能遵守 PRD 第 15.3 节 P2 顺序；同时应修正“已完成”描述，避免把最小页面当作完整验收。
